## 🛠️ How to Add or Update Skills in the Future

### 1. Update an Existing Repository
If a repository author releases improvements or fixes:
```powershell
# Example: Update all Cloudflare skills
npx skills add cloudflare/skills

# Example: Update only a single specific skill from a repo
npx skills add addyosmani/agent-skills --skill doubt-driven-development
```

### 2. Add a Brand New Skill from GitHub
```powershell
# Add from GitHub repository
npx skills add <github-username>/<repo-name>

# Add from a specific subfolder or single skill
npx skills add <github-username>/<repo-name> --skill <skill-folder-name>
```

### 3. Keep Active vs Store Synchronized
- **Full Store**: `D:\Repo\.agents\skills` holds all 594 installed skills.
- **Active Hot Set**: `D:\Repo\.agent\skills` holds the curated ~89 skills that fit inside the context token budget.
- To activate any skill from the store into your hot set:
  ```powershell
  python D:\Repo\.agents\library\activate_skill.py <skill-name>
  ```
- Any new skill installed with `npx skills add` will be recorded automatically into `D:\Repo\.agents\skills-lock.json`.
