1. Install Entire AgentSkills Vault (My Repo)
Recommended · All 6,063 Skills
Clone the complete vault directly into your project's .agents directory. Includes all 38 categories, 210 curated repositories, automation tools, and catalog data.
Standard Git Clone (Windows / macOS / Linux): Copy
git clone https://github.com/SeaXen/agentskills.git .agents
Git Submodule (into an existing repository): Copy
git submodule add https://github.com/SeaXen/agentskills.git .agents
Tip: After cloning, all skills in .agents/skills/ are automatically recognized by Google Antigravity, Claude Code, and Windsurf.
2. Install One Individual Skill (Targeted)
Zero Clutter · Single Stroke
Activate or install an individual skill without downloading the whole vault. Works universally via NPX or the local Python CLI.
Universal NPX Stroke (Origin or My Repo): Copy
npx skills add https://github.com/SeaXen/agentskills --skill <name>
Local Python Activation (Copies into active workspace): Copy
python .agents/library/activate_skill.py activate <name>
Zero-Disk Junction / Symlink (0 duplicate disk space): Copy
python .agents/library/activate_skill.py link <name>
Tip: You can click the 1-click install box on any row in the Skill Hub table for instant copying!
3. Install / Activate Entire Category Pack
38 Domain Packs
Need all Frontend Component skills, all Security audit tools, or all Cloudflare Edge recipes? Activate a full domain pack with one command.
Activate All Skills in a Category: Copy
python .agents/library/activate_skill.py activate-category <slug>
Zero-Disk Link Category (Junction / Symlink): Copy
python .agents/library/activate_skill.py link-category <slug>
Example: Activate all 49 Frontend UI Component Skills: Copy
python .agents/library/activate_skill.py link-category frontend-ui-components
Tip: On the Categories tab, each card has a 1-click button to copy its specific activation stroke.
4. Install Full Upstream Repository
210 Verified Libraries
Install or activate an entire upstream collection (e.g. Cline skills, Antigravity Awesome Skills, or Anthropic Knowledge Work).
Universal NPX Repo Install: Copy
npx skills add <upstream_github_url>
Activate All Skills from a Local Library Repository: Copy
python .agents/library/activate_skill.py activate-repo <repo>
Clone Upstream to Local Library: Copy
git clone <upstream_url>.git .agents/library/<repo>
Tip: Browse the Library tab to view all 210 repositories with skill counts and direct links.
5. Lifecycle: Manage, Deactivate & Update
Workspace Maintenance
Easily audit which skills are currently active in your agent context, remove unused ones, or pull the latest improvements from GitHub.
List All Currently Active Skills: Copy
python .agents/library/activate_skill.py list
Deactivate / Remove a Skill from Active Workspace: Copy
python .agents/library/activate_skill.py deactivate <name>
Update All Skills & Vault Catalog from Upstream: Copy
python .agents/library/activate_skill.py update
Tip: Deactivating a skill safely removes it from active prompt context while preserving it in your offline reserve library.
6. Cloudflare R2 Sync & Cloud Deployment
8 Targets Supported
Host your private or community Skill.Sea catalog across Cloudflare Pages, Vercel, Docker, Render, Fly.io, or Railway with S3-compatible R2 storage.
Sync Catalogs to Cloudflare R2 Storage: Copy
npm run sync:r2
Run Skill.Sea Local Development Server: Copy
npm run dev
Deploy via Docker Compose: Copy
docker compose up -d
Tip: Skill.Sea requires zero external databases — runs lightning-fast on 100% static JSON datasets.
