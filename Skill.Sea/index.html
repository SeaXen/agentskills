How to Install & Use Skills Anywhere

Complete guide for integrating these 6,063+ skills with Google Antigravity, Claude Code, Cursor, Windsurf, or custom agent setups.

Method 1: Local AgentSkills CLI

Activate any skill into your active workspace using the universal Python activator:

Copy python .agents/library/activate_skill.py activate <name>

Copies the skill definition and instructions directly into .agent/skills/<name>.

Method 2: Zero-Disk Symlink / Junction

Link skills without duplicating disk space using native Windows NTFS Junction or Linux symlink:

Copy python .agents/library/activate_skill.py link <name>

Uses 0 duplicate disk space. Edits to upstream automatically reflect.

Method 3: Remote cURL Quick-Launch

Install and activate directly in GitHub Codespaces, Linux VMs, or CI pipelines:

Copy curl -sSL https://raw.githubusercontent.com/SeaXen/agentskills/main/install.sh | bash -s -- activate <name>

Automatically clones or pulls the vault and configures your environment.

Cloudflare R2 Sync Integration

Back up and sync your entire catalog to Cloudflare R2 object storage:

Copy npm run sync:r2

Uploads catalog.json, categories.json, and repositories.json using S3 API.
