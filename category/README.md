## 🚀 How to Browse & Activate Skills

### 1. Browse by Category in VS Code
Open the [`.agents/category/`](./) folder in your IDE file tree. You can immediately expand any category folder (e.g., [`frontend-ui`](./frontend-ui/) or [`security-audit`](./security-audit/)) to explore every skill's files directly!

### 2. Search Skills by Category via CLI
Search for any skill or filter by category:
```bash
python .agents/update.py --find <keyword>
```

### 3. Activate Any Skill to Your Active Workspace
Bring any skill into your active workspace hot-set with zero latency:
```bash
python .agents/library/activate_skill.py link <skill-name>
```
