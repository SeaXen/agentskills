# Deliverable specs - precision is the anti-dispute mechanism

"3 short videos" is the canonical ambiguous deliverable (corroborated - every published source insists on specifying beyond a format name). Disputes come from what it silently fails to say. The brief specifies the signed deal's deliverables to this precision, and never adds or removes a deliverable the deal didn't include.

The formats below are deliberately not ranked against each other: the deal already fixed which ones ship, so an efficiency order over them would be false precision applied to a decision nobody is making here. Rank formats in the discovery and negotiation skills, where the choice is still open.

## Precision fields per deliverable

Fill every field that applies. Write "creator's choice" explicitly where a field is deliberately left open - silence reads as an oversight, not a freedom.

- Platform or channel type (short-form video platform, professional network, newsletter, podcast...)
- Format (in-feed post, story-format placement, short-form video, long-form video, sponsored newsletter slot, host-read segment)
- Quantity
- Duration or length (seconds for video/audio; word count for written)
- Aspect ratio (visual formats)
- Caption requirements, hashtags, and required @mentions
- Link destination and mechanism (link sticker, bio link, description, embedded link)
- Promo code and where it must be visible (spoken, on-screen, caption)
- Music/audio licensing constraint (see the paid-amplification trap below)
- Draft deadline
- Posting window (dates, and time-of-day only if the deal set one)
- Disclosure placement for this specific format
- Raw-file delivery format, if the deal includes asset handover

## The paid-amplification and audio-licensing trap

- If the content may ever run as paid media, declare it in the brief before the creator picks music: trending platform audio is generally not licensed for paid amplification (single-vendor, mechanically checkable). Declaring it after the fact forces a re-edit.
- Same trigger in B2B: thought-leader ad formats promote the creator's own post as-is, and edits must come from the original author - paid-readiness is settled before the organic post goes live, or promotion requires a re-post (single-vendor).
- The usage window, whitelisting rights, and exclusivity are deal terms: the brief points to them and never sets or restates them.

## B2B deliverable fields (inference - no published B2B spec list was found)

- Sponsored newsletter slot: word count, position in the issue, number of links, subject-line mention yes/no, disclosure line.
- Host-read podcast segment: duration, placement (pre/mid/post-roll), talking-point count, code read aloud, disclosure spoken at the segment start.
- Long-form professional-network post: length, first-line disclosure, link placement (post vs first comment - state which), paid-amplification intent.
