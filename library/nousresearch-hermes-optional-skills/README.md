```powershell

```

### 2. 🔗 Link (Symlink without copying)
```powershell
python .agents/library/activate_skill.py link <skill-name>
```

### 3. 🗑️ Deactivate / Remove
```powershell
python .agents/library/activate_skill.py remove <skill-name>
```
