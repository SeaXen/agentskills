A browser-native deck is a slide presentation made with HTML. It can include
interaction, animation, live examples, and links while remaining easy to open
and share.

## What HTML adds

HTML decks can respond to input, reveal a sequence, run a small demo, or show
live data. They can also be inspected and changed with the same tools used for
other web artifacts.

## Keep it usable as a presentation

A deck still needs readable slides, dependable arrow-key navigation, visible
progress, and a layout that fits the screen. A fixed 16:9 stage is usually
simpler than treating every slide like a responsive webpage.

## Use motion when it helps

Animation is useful for sequence, comparison, and change. It should not be
required to understand the slide, and the deck should respect reduced-motion
settings.
