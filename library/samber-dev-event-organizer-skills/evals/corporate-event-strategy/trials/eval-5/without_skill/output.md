## Before you lock this

1. **Targets are blank.** Without numbers, "drive pipeline" can't be judged as met or missed. If you don't have them yet, the exec review should at least see the baseline and the method for setting targets.
2. **"Data source: TBD" is the weakest line.** Execs will probe it, since a pipeline goal depends on an attribution definition. Try to get a 15-minute Sales Ops sync before Monday and write the agreed definition in. If that can't happen, put the date it will be settled in the doc instead of "TBD".
3. **"Community engagement" needs one concrete action.** Pick the single follow-on action that counts (for example, joined the community). Several loosely defined engagement signals read as vague.
4. **Pipeline lags the event.** I added the 90-day read-out because a wrap-up two weeks after the event can't show pipeline results. Cut it if your director prefers one read-out.
