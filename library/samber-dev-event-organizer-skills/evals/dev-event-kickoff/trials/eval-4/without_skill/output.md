**Week 2: new targets and the CFP**
1. Send a personal outreach batch to new targets: 20–30 named accounts, one note each, a 15-minute call as the ask.

3. Publish the CFP, and publish a landing page with the fixed date and an early-bird or waitlist signup.
4. Email past attendees once.

**Weeks 3–4: pipeline work**
1. Hold discovery calls. Offer track or theme alignment where it fits a sponsor's goal.
2. Send proposals fast. Aim for a proposal within 48 hours of each call.

**Weeks 5–6: close**
