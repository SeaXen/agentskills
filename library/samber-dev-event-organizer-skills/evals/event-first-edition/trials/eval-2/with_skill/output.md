**Administrative first steps**, in order, before any public announcement:
1. Publish the code of conduct. It is the earliest hard gate, ahead of venue and date.
2. Set up a neutral shared event email alias as the public contact, not a personal or company address.
3. Set up a shared credential vault.
4. Join a peer-organizer network.
