## 2. Hard gate: is ShipIt Hack ready to be a second property?

## 4. Gaps in the plan that block "done"

The skill's pass test is that every property has a purpose sentence, a named owner and a written kill criterion. Today you have owners only.

Write these before you sign:

- **Purpose:** one sentence per property, from you and the owners. For example, what is the podcast for? A property nobody can describe in a sentence is the first kill candidate.
- **Funnel paths:** for each pair, mark it *exists* or *aspirational*. Examples: does the meetup list feed the conference's first email? Do podcast listeners ever buy conference tickets? Is anything said at the conference about the hackathon?
- **Kill criteria:** per property, a named metric, a floor, and the number of consecutive editions below it that triggers a conversation. For example: "participants who appear at another property within 12 months, floor N, two editions in a row". Choose N yourselves. I'm not inventing numbers for you.
- **Bus factor:** who covers each owner if they're out? You have four people and three owners named. Who is the fourth, and what do they own?
