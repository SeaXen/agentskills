# Deliverable: launch announcement for the new name

**Two things to know first.**
- **Fit.** The announcement is honest about the program, which is still about 85% JVM. If it claims a polyglot program that isn't there, attendees and non-JVM sponsors will notice at the first schedule. I wrote it as "JVM stays the core, and we're widening the room", so every claim is true on day one. Items in [brackets] are facts only you have.
- **Cause.** 620 vs 640 is a 3% dip, which is within normal year-to-year noise. It is weak evidence that the name is the problem. This doesn't block the announcement, but I'd tie the rename to a concrete program change, such as one new non-JVM track. Otherwise it reads as a logo swap.

- **Sponsorship.** We are opening new sponsor categories beyond JVM vendors. Details are in the updated prospectus: [link].

**What is not changing**

- **The JVM stays the core.** Spring, Kotlin, GraalVM, and the JVM ecosystem remain the heart of the program. Most of the [YEAR] schedule will still be JVM content, and that is deliberate. The people who made this conference are the reason it exists.

**Why we are doing this**

Developers rarely work in one language anymore. A Kotlin service talks to a Rust component, a TypeScript frontend, and a Python data pipeline. The old name asked people to leave that reality at the door. The new one doesn't, and it still keeps the JVM at the center.
