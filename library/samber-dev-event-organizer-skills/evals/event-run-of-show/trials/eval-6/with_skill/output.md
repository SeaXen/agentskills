# Day-of document depth: single-room first edition, live opening, verbatim sponsor line

**Assumptions:** one room, about 3 organizers who see each other all day, a recurring event, and a community-run pole. Tell me if any is wrong, because it changes the depth.

## Verdict

Write a **layered document**. Depth varies by segment, not by hour.

| Layer | Where | Why |
|---|---|---|
| **Word-for-word script** | Opening only (the 20 min on YouTube) | Four promotion conditions apply: livestream, contractual verbatim line, first edition, one briefed host. |
| **Scripted transitions** | Opening → first talk, each handover, stream end, closing | Dead air is visible live, and the stream makes it public. |
| **Timed grid with named owners** | Everything else | Cheap. It is the grid plus an owner, tech and escalation column. |
| **Skipped** | Per-slot setup budget, radios, role channels, paired duty | A single room doesn't need them. Add a setup budget only if a slot has live demos. |

I am trimming one thing from the skill. A full word-for-word script of 20 spoken minutes is too costly for your 3 hours. Write exactly these parts and use bullet prompts for the rest:
- The first 90 seconds.
- The stream-specific lines (hello to YouTube, where chat questions go).
- The sponsor lead-in, the sentence itself, and the lead-out.
- The handoff line into the first talk.

The practical info (wifi, toilets, schedule) stays as prompts.

## Print target: 4 pages plus 1 card

1. **Page 1:** roles by name, on-duty per block, org channel, both escalation paths, emergency-plan contacts.
2. **Page 2:** the opening, with scripted lines and the stream cues.
3. **Page 3:** cue sheet for the rest of the day. Each row has clock, room, owner, tech, what is said, what moves, and who to escalate to.
4. **Page 4:** disruption sequence, handoff checklist, closeout.
5. **Lectern card:** the sponsor sentence alone, in large type.

## The verbatim sentence

- Copy-paste it from the contract. Never retype it.
- Name the reader. A second person checks the printed card against the contract.
- The reader rehearses it once aloud before Saturday. The stream records it, so you can't fix a misread afterward.
- I haven't seen the sentence, so none of it appears here.

## Roles (by name, not function)

- **MC:** one briefed host for the opening.
- **Speaker introducer:** a different person from the MC, per session.
- **Organizer on duty:** not the MC and not a speaker. This is the escalation target.
- **Room lead:** owns the clock. Define what they may decide alone and what they escalate.
- **Stream operator:** my addition for your livestream. This person watches the feed and chat so the MC doesn't have to.

## Comms

Use one organizer-only channel, such as a phone group, separate from any attendee channel. Add a live line, such as a call or standing in the same room, only if the stream operator sits away from the room. No radios.

## Rotation

Publish one named on-duty person per block on page 1. Use the six-section handoff checklist, with an entry or an explicit "none" in each section. Do a live channel check at any shift change.
