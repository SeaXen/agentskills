# Sablewood lightning talks: run plan

The rules email isn't a control. Last time's speakers had the same rules and the block still ran 20 minutes over, so this plan enforces the format with people, a timer and a single laptop.

I assumed you have at least 3 volunteers and a projector with one HDMI or USB-C input. I haven't seen your venue, so adjust to fit.

## 1. Roles (3 people, none of them a speaker)

- **Host:** announces speakers, fills any gap, makes the call to cut a talk.
- **Timekeeper:** runs the visible clock and holds the cue cards. They sit in the speaker's line of sight, front row center.
- **AV:** owns the one stage laptop, the adapters and the slide deck. Sits at the laptop.

## 2. Remove the mirroring failure

1. **Use one stage laptop.** It's yours and it's tested, and no speaker plugs in.
2. **Collect slides by T-24h.** Ask for PDF or PPTX, plus fonts and videos embedded. Anyone missing at T-24h gets a chase message.
3. **Merge everything into one deck.** Put a "Next up: Name – Title" card between talks. The card fills the handoff gap.
4. **Handle demos in one of three ways:**
   - Record them and embed the video.
   - Run them on the stage laptop.
   - Run them live on the speaker's own laptop, only if the speaker insists. In that case they must pass a 5-minute test at T-30. Keep the adapters (USB-C, mini-DP, HDMI) in a labeled bag.
5. **Use a 45-second fallback rule.** If a speaker's laptop isn't showing in 45 seconds, AV switches to the stage laptop's PDF and the talk starts anyway. There is no troubleshooting on stage.

## 3. Enforce the 5 minutes mechanically

- **Use a big countdown** on a floor monitor or second screen facing the speaker, readable from 5 m. A phone on the floor isn't enough.
- **Timekeeper cues:**

| Time | Cue |
|---|---|
| 0:00 | Clock starts when the speaker says the first word |
| 3:00 | Green card, "2 min left" |
| 4:00 | Yellow card, "1 min left" |
| 5:00 | Red card plus a soft chime |
| 5:30 | AV switches the deck to the next card and the host walks up, applauding |

- **The cut is non-negotiable.** Tell speakers about it in the briefing, and also tell the room: "We clap anyone off at 5:30. It's a feature."
- **Questions go to the break.** The host says "Find them at the break" every time.
- **Add a transition budget** of 30 seconds per talk. The next speaker stands at the side during the previous talk, with the clicker in hand and the deck already on their slide.

## 4. Schedule (T = block start)

| Slot | Start | Notes |
|---|---|---|
| Talk 1 | T+0:00 | |
| Talk 2 | T+5:30 | |
| Talk 3 | T+11:00 | |
| Talk 4 | T+16:30 | **Checkpoint:** must end by T+22:00 |
| Talk 5 | T+22:00 | |
| Talk 6 | T+27:30 | |
| Talk 7 | T+33:00 | Ends T+38:30 |
| Buffer | T+38:30 | 1:30 spare |
| Break | **T+40:00** | Advertise this time |

- **If you're late at the checkpoint,** the break shrinks. The talks don't.
- **If a speaker is missing,** skip them and move on. Don't wait, and don't redistribute their time.
- **Ordering:** put anyone with a demo, or who overran in the past, in slots 2–4. The host can absorb any slip before the end. Slot 7 should go to your most disciplined speaker.

## 5. Dead-air plan

The 4-minute gap happened because nobody owned it. The host now owns it.

- Keep 3 fillers on a card: sponsor and venue thanks, the next event announcement, and a 1-minute quiz question.
- Any gap over 20 seconds, the host talks. If AV needs more than 45 seconds for a fix, the host says "we'll come back to this one" and calls the next speaker.

## 6. Speaker briefing

The 3-week-old email is stale. Send a short message at T-24h with the slide deadline and these 4 lines:

> 1. Your slides go on the stage laptop. Don't bring yours up.
> 2. Be in the front row by T-15 in running order.
> 3. You get cue cards at 3:00, 4:00 and 5:00. We cut at 5:30.
> 4. Questions go to the break.

Repeat it out loud at T-15 with all 7 in the room.

## 7. Day-of timeline

| When | What |
|---|---|
| T-60 | AV loads the merged deck, tests audio and clicker, lays out the adapter bag |
| T-30 | Run the 5-minute tests for any live-demo laptops |
| T-15 | Speakers seated in order, spoken briefing, timekeeper checks the clock and cards |
| T-0 | Host welcomes the room, states the cut rule, starts |
| T+40 | Break |

## 8. After the block

Log the actual start and end time of each talk. If any talk ran over, adjust the next event's order or the transition budget with that data.
