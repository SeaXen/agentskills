## 1. Application form: 14 fields down to 10

**Organization**
1. Organization name
2. Website
3. Contact email

**Event**
4. Event name
5. Description (max 100 words)
6. Format (talk, workshop, party, dinner, other)
7. Headcount
8. Ticketed (yes/no)
9. Venue
10. Start and end time

**Cut or moved:**
- **Why it's a good fit (150+ words):** merged into the description. Add one line to field 5: "Say what attendees get and why it suits Summit guests."
- **Minimum word counts:** now a maximum. A minimum rewards padding, and a cap makes applicants say what matters.
- **Logo upload:** collect it from accepted events only, for the listing.
- **VAT number:** collect it on acceptance, and only if money changes hands.
- **Social handles:** the website covers it. Add an optional field only if you actually vet by social.

**Add a rule above field 10:** "Events may not overlap the opening keynote or main-stage sessions." This catches the clash you just had at submission, before it reaches your inbox.
