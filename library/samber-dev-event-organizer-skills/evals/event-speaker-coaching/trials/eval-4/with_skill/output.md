## 8. Rules the coaches need to know

- **Three changes per round** at most, Blocking included, plus specific keeps. Notes point at a moment, never at the person.
- **Blocking is rare.** Only two cases qualify: the run still exceeds the full talk time after agreed cuts, or the deck fails a Blocking accessibility item (contrast below 4.5:1, flashing more than 3 times a second, meaning carried by colour alone). Missing the 90% mark alone is a strong Change note, not Blocking.
- **A Blocking note goes to the speaker first.** Escalate to the program chair only if they decline or can't fix it by the freeze, and tell them before you do.
- **Over time is fixed by cutting whole sections**, never by "talk faster".
- **No notes on accent, pitch, confidence or appearance.** Notes like "at minute 12 the back row lost you" are fine.
- **Gates:** every speaker who took a dry run ends their last listener run by about 90% of talk time. Every deck clears the Blocking accessibility items before the slide deadline.
