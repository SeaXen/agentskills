## Problem 1: first-come-first-served

- It rewards the speakers who answer fastest, who are often the most confident.
- Speakers who most need a listener answer last and get no slot.
- Use this rule instead, and write it in the offer:
  1. Everyone gets the same offer, in the same words.
  2. Places go first to speakers who say, in intake, that this is their first talk at an event this size. Ask everyone the same question.
  3. A lottery fills the remaining places.
  4. Speakers without a place get the rehearsal kit, and they can still opt in to anything.

## Format fixes

**30-min talks (no Q&A in the slot)**
- Talk time is the full 30 min. The pass mark is the run ending by about 27 min.
- Blocking only if the run still goes past 30 min after the agreed cuts. Missing 27 is a strong Change note, not a Blocking one.
- Tell speakers questions go to the hallway before they rehearse. The listener can still ask 2 hard questions out loud, untimed, so speakers rehearse the hallway answers.
- Speakers need to know they will be easy to find after the talk, and where.

**Ignite lightning (20 slides × 15 s = fixed 5:00)**
- The clock is the deck, so the 90% rule does not apply. Pass = a run with auto-advance on, where each slide's point fits its 15 seconds and the last sentence lands on slide 20.
- Fix an overrun by cutting words per slide. Section cuts do not work here.
- Rehearse with auto-advance on. A solo run with auto-advance on counts as practice. Only a listener run counts as the gate.
- Accessibility check applies as usual. Add this for the captioners: text per 15-second slide must be readable, and a script or notes should reach them with the deck.
