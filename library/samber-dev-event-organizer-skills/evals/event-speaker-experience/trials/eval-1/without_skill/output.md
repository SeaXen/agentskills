# Havenport Devcon: speaker kit for the 11 accepted speakers

## ⚠️ Check the printer date first

Today is 15 October, so the 14 October programme deadline passed yesterday. Either the date is a typo or you're already a day late.

1. Call the printer today and ask for the latest date they can still take the PDF. Call that date **D**.
2. Use D in the deadlines below. If the printer can't move, treat D as today and cut the speaker deadline to 48 hours.
3. Badges are printed the same week, so they run on the same data. Don't send a second request for badge info.

## Step 0: fix the sender problem before you send anything (today)

- Create one shared address, for example `speakers@<your-domain>`. All 11 speakers write to it and every organizer reads it.
- Name one owner per email thread, for example 11 speakers split across the 3 organizers. Replies still go through the shared address.
- Each of the 3 organizers forwards their existing speaker threads to the shared inbox and stops answering from a personal account.
- Open the email with a short note that this is the permanent address. Speakers who got replies from three different people need to know why.
- Collect everything through **one form** (or one shared sheet), not by email. Replies by email scatter bios and photos across three inboxes.

## Chasing plan (the one thing that protects the PDF)

1. **D minus 4:** reminder to everyone who hasn't filled in the form.
2. **D minus 3:** form closes. For anyone missing, the owning organizer phones or messages them directly.
3. **D minus 1:** send the proofs to all 11 for a final "this is how you appear" check. Allow a one-hour reply window for typos only.
4. **D:** send the PDF to the printer.

Track the 11 speakers in one sheet with these columns: name, session type, owner, confirmed, form done, headshot, bio, badge name, dietary/access, recording consent, slides, tech check slot, chased on (date).
