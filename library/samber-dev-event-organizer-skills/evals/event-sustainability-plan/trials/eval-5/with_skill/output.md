## Why not "9.8 tonnes CO2e, down 76% on last year"

1. **It compares unlike boundaries.** Last year's 41 t included travel. This year's 9.8 t covers only venue, food and waste. Travel is usually 80–97% of an event footprint. A 76% fall that comes from dropping the biggest line is a boundary change, not a reduction. The skill treats this as misleading by omission, and the UK CMA Green Claims Code covers it for a Manchester event.
2. **It mixes factor editions.** You are comparing the old DESNZ edition against the newest. DESNZ air factors can move 15–40% between editions, so last year has to be restated on the new basis before any comparison.
3. **I can't confirm the 9.8 t.** I tried to fetch the current DESNZ set and the fetch was denied, so I have no cited factors. Check the 9.8 t against the published factors before it goes anywhere public.
4. **The arithmetic works only on the wrong basis.** (41 − 9.8) / 41 = 76%, which confirms the headline is just the travel line missing.
