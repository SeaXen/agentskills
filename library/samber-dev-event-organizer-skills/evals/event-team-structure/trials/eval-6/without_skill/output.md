**There is no standard organizer-to-attendee ratio for tech conferences.** I know of no published benchmark, so I wouldn't put one in a board deck as an industry figure. The ratios people quote come from individual organizers' experience and vary widely with paid staff versus volunteers, number of tracks, and venue.

**What I'd put in the deck: 15–20 core organizers for about 2,000 attendees.** That is my own planning heuristic, not a sourced number. It works out to roughly 1 core organizer per 100–130 attendees. Present it as a planning assumption.

**Why it isn't a straight ratio**
- Core team size is set by workstreams, not headcount: program, sponsors, venue and ops, comms, finance, and volunteers. Each needs an owner whether the event has 700 or 2,000 attendees.
- Core roles scale sublinearly. A 2.9x attendee increase usually needs about 2x the core team, not 2.9x.
- Day-of staff and volunteers do scale roughly linearly, at about 1 per 15–25 attendees. Show these as a separate line from the core team.

**Better method: scale from your own numbers.** Take your current core headcount and multiply by about 2. If you have 8 core organizers today, plan for about 16. This is more defensible to a board than any outside ratio, because it rests on your own event.

**Two things would change the number:**
- **Paid staff or agency:** if you add them, the volunteer core can be smaller.
- **Extra tracks, workshops, or a new venue:** each adds workstreams and pushes the number up.
