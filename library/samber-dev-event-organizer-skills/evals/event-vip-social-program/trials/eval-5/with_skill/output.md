## Verdict

Your plan is a separate venue, on the same evening as the party, run by you while you run the event. Three rules in the skill rule that combination out:

- **Owner conflict.** You are on site all day and would own the bar, the transport and the headcount. The skill deletes "a separate evening at a separate venue" when the named owner is also running the main event that day. A second venue with fixed headcount and transport becomes your job on top of running the event. If a teammate who isn't running the event takes the bar, transport and headcount, this rung comes back.
- **Overlap.** A 20:00 drift-out during a 19:00-until-late party is the first failure mode in the skill. Everyone sees where the interesting people went, and the party becomes the consolation room. Eight people leaving a 600-person party reads as a tier.

## 3. The list

- **Fields:** name, why this seat exists (one sentence, no rank), who put the name forward and when, answer given and date, and access needs only where the person supplied them.

## 4. Invitation and access (Menu B)

- **Door page:** alphabetical names only. If a name is missing, take it and fetch the owner. Say "It's a private meeting, it'll be done shortly." Never read the list aloud.
