## PortMesh Summit: volunteer rest space and lunch

**Do first:** pull up the shift grid. Find each volunteer's longest off-post block and compare it to the buffet hours. Everything below depends on that overlap.

### 1. Quiet room as volunteer crash space: no

- ❌ The quiet room is provisioned for attendees who can't be around noise and interaction.
- Filling it with off-duty volunteers destroys the property it was booked for. Its calm depends on it staying empty.
- "Rarely full" is not the same as "free". The skill treats this as a deleted option, not a low-ranked one.
- Don't use a different quiet or accessible corner either.

### 2. Use the spare seminar room for volunteers (my recommendation)

- It is the only room that fits a volunteer rest space.
- You have a 12-hour day, and a room you can hold all day is available. Both facts make a rest space the right choice.
- Stock it with:
  - seating
  - water
  - self-serve snacks
  - a written line saying "you may be here while off post"
- Fund it as its own small budget line. Don't draw on sponsor, speaker or attendee allocations.
- The sponsor request is a separate decision for whoever owns sponsor deliverables, and I haven't judged it.
- If sponsors get the room, volunteers get no rest space. That is a defensible choice, but make it deliberately and don't let it happen by default.
- ⚠️ First check whether any sponsor contract already promises a room.

### 3. Missed lunch is a grid problem, so fix it upstream

- Don't patch it with food alone, and don't edit the grid from here.
- Send this requirement to whoever owns the shift plan (`event-volunteers`):
  - **Every volunteer gets one continuous off-post block that overlaps the buffet window.**
  - Stagger the 22 volunteers across the window, so nobody leaves a post uncovered.
- Don't let anyone read this as permission to slip away when it's quiet. A volunteer leaves a post only once a replacement is confirmed.
- Check this against the grid before anything is published. If any volunteer lacks a block, the entitlement isn't funded. Don't promise it until it is.

### 4. A better menu than attendees get: access, not a premium menu

- The caterer and the dietary and allergen policy are set once for everyone (`event-hospitality`). Don't build a second volunteer menu.
- The volunteer top-up is **access**:
  1. Ask the caterer to hold back an allocation, so late-break volunteers don't queue behind 450 people.
  2. Agree a queue-skip rule, so a short break isn't spent in line.
  3. Keep the held portions inside the general menu.
- Vegan and coeliac volunteers:
  - Count the portions you need: 2 vegan and 1 coeliac, plus any others from sign-up.
  - Ask the caterer to set those aside, labelled and handled so gluten doesn't cross-contaminate. That is the general allergen standard, applied to the held allocation.
  - Give the caterer counts only. Don't carry volunteers' dietary answers into the retained list. Delete them at closure.
- If you want a nicer volunteer meal on top, such as an after-event dinner, that is a separate budget line with a payoff mostly next edition. Decide it only if the event recurs.

### 5. Off-duty time: add a pointer

- Send off-duty volunteers a short live note on what is running now and where there is room.
- It costs almost nothing, and shifts of 2–3 hours inside a 12-hour day already leave most people some free time.
- If the grid check in section 3 shows anyone without a free block, publish the minimum off-post block as an entitlement. Once the grid funds it, say so in the plan.

### Questions that would change this

1. How long is the buffet window? Is there a gap before volunteers' breaks?
2. Does the grid already give everyone a continuous block off post?
3. Is this a recurring event, and did volunteers give up a ticket to staff it? If so, named session blocks move up the list.
4. Are any volunteers minors, or working under someone else's insurance? If so, send that question to counsel and the insurer, because this skill doesn't answer it.

### Before you send anything

- Show me any volunteer-facing message or published entitlement before it goes out.
- At closure, thank volunteers by name only with their consent, and set an owner and a deletion date for the retained list.
