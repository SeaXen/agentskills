## Verdict

Don't open a standing Discord yet. The missing piece is a second person, not a platform. A Discord also isn't free: it costs someone's attention every week.

## Must fix before talk 1

1. **Second person on the day.**
   - You introduce the speaker, then sit in the talk. Nobody is left to watch chat, collect questions, fix audio, or ban a spammer.
   - Assign a producer or moderator. Name a backup.
   - Run a 10-minute tech check with each speaker the day before.
2. **Moderation, if you open any public chat.**
   - Open to anyone means spam, raids, and DMs to attendees.
   - Publish a short code of conduct before the first join.
   - Give two report paths: one to the moderator, one to someone else, so a report about the moderator has somewhere to go.
   - Set the Discord entry gates and rate limits before launch.
   - Moderators need to be present live. A rented chat nobody watches goes bad fast.
3. **Dates are tight.** Today is 2026-10-17. Autumn ends around 21 December.
   - Plan on a mid-November talk 1, then early December, then January. Skip the holiday weeks.
   - Promotion needs 3 to 4 weeks, so start now.
4. **Talk platform.**
   - Pick a tool built for webinars or live streams. Check it handles registration, recording, captions, and a Q&A queue.
   - Discord is weak at "open to anyone" registration and reminders.
5. **One goal.**
   - Choose a primary outcome: collaborators, hiring, authority, or feedback on your research.
   - Set a number for it now, for example "30 live attendees per talk" or "5 collaboration inquiries".

## Do instead of a standing Discord

1. Use the chat built into the talk platform for the live Q&A.
2. Move follow-up questions to a **time-boxed channel or thread** that stays open for about a week after each talk.
3. If your code lives on GitHub, use GitHub Discussions. It's indexed, you own it, and it needs no new account.
4. After talk 2, check these signals before opening a permanent space:
   - Do people ask follow-up questions unprompted?
   - Do attendees answer each other?
   - Can you personally name 20 or more people to invite?
   - Does a named person have 1 to 2 hours a week to keep it going?
5. If any of those fail, skip the Discord. An empty server makes the lab look dead.
