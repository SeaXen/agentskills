# Register definition and the touchpoint matrix

The identity/expression split is drawn from established brand tone-of-voice practice.

## The identity/expression split

The load-bearing rule from brand-voice practice: **voice (identity) is fixed; tone (expression) modulates by context**. Applied to an event: the cultural register - hacker, corporate, design, business, or a deliberate blend - is fixed once chosen; how it shows up modulates by touchpoint and by moment.

The single most common failure in brand-voice work is confusing the two - redesigning the identity per channel instead of modulating its expression. The event version: an organizer who re-decides "the vibe" separately for the website, the MC, and the swag ships three small identities instead of one.

## Register attributes: the "X, but never Y" format

Define the register as 3-5 attributes, each shaped "X, but never Y" (the brand-voice convention, e.g. Slack's "Confident, never cocky"). Event examples:

- "Irreverent, but never unsafe"
- "Scrappy, but never sloppy"
- "Polished, but never corporate-sterile"
- "Insider-warm, but never gatekeeping"

Each attribute carries:

- A one-line definition.
- 3 do's.
- 3 don'ts.
- 1 example.
- 1 anti-example.

**Pull the example and anti-example from the event's own past edition wherever one exists**, never invented. For a first edition, borrow the anti-example from a named event the organizer wants to not be, and say so.

### Anti-midpoint rule

Brand-voice practice (NN/g's four tone dimensions, applied to events) warns against clustering every axis at the midpoint: lean clearly to one side on most axes, because mid-range scores produce a bland, forgettable identity. Event-specific axes to lean on:

- spontaneous ↔ choreographed
- insider ↔ newcomer-welcoming
- irreverent ↔ formal
- austere ↔ lavish

An organizer whose self-description hedges every axis - "welcoming but professional, fun but serious" - has not chosen a register yet. That is a finding to surface, not a neutral input to accept.

### Banned-register list

A banned-vocabulary/banned-register list retains better than a desired-words list (brand-voice practice: prevention beats prescription). Examples:

- No corporate-speak ("synergy", "leverage", speaker-as-"content") at a hacker-register event.
- No inside jokes that exclude first-timers at a newcomer-welcoming event.
- No exclamation-mark whimsy in an incident announcement, anywhere.

## The tone-modulation matrix

The operational core of the deliverable - consulted more often than the narrative principles (both brand-voice sources report this independently). Rows are event moments; columns are touchpoints. Every cell answers: how does the fixed register express itself here?

| Opening              |                |                        |      |                       |                          |                |

Adapt rows and columns to the event - a hackathon adds "judging & demos"; a conference with a party adds "evening program". Fill only the cells where the answer is not obvious from the attributes alone; a matrix of restated attributes is padding.

### Worked example rows (illustrative, not drawn from a real event's guide)

Hacker-register event, "Irreverent, but never unsafe":

- **Opening × MC script**: open cold with a story or demo, never logistics; self-deprecating humor fine, punching down never.
- **Incident × MC script**: drop the irreverence entirely - plain, direct, factual; name the next concrete step. The register's "never unsafe" clause outranks its "irreverent" half.
- **Sponsor interactions × signage**: thank sponsors in the event's own voice (!!Con labels even its captioning sponsor with the same exclamation-mark register it uses everywhere), never in the sponsor's press-release voice.

Corporate-register event, "Polished, but never sterile":

- **Breaks × catering presentation**: production quality visible (signage, flow, no queues), with one human touch per break - a local item, a named barista - so polish doesn't read as anonymous.
- **Opening × MC script**: professionally hosted and rehearsed, first 90 seconds scripted; warmth carried by specifics about this audience, not by generic energy.

### Negative example: the inconsistency row

The failure the matrix exists to catch, one row wide: stated register "community-first, volunteer-run, everyone's conference" - but the opening is a sponsor-logo reel, the party outspends the program, and speakers get a green room while volunteers eat standing. Each touchpoint is individually defensible; together they announce a different identity than the stated one. Audit cell by cell and the contradiction is visible; audit by overall impression and it hides.

## Community vs vendor: how each pole encodes values in touchpoints

The table below contrasts how the two poles express identity. Use it to populate the matrix's columns for whichever pole the organizer chose - and to audit for cross-pole contradictions.

| Touchpoint           | Community/hacker pole                                                                                             | Vendor/corporate pole                                                                                                           |
| -------------------- | ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Venue                | "Third places", civic/unusual venues (Strange Loop's theatres and City Museum); a self-built temporary city (CCC) | Convention centers and produced environments; budget disproportionately on A/V and staging (HashiCorp's stated rule)            |
| Pricing & labor      | Pay-what-you-want (!!Con), volunteer-run (CCC Angels), moderate pricing, scholarships                             | Marketing-budget-funded, professionally staffed; price signals production value                                                 |
| Session format       | Single track, lightning talks, hallway track, open space - formats that flatten hierarchy                         | Keynote-driven, curated narrative; the CEO keynote as identity-setter                                                           |
| Commercial norms     | Values said out loud: no sold keynotes, no mailing-list sales, no sales pitches (Strange Loop, DevOpsDays)        | Commercial frame softened through "family"/community framing - honest when backed by real community investment, veneer when not |
| Hosting & production | Tone-setting distributed among organizers who embody the norms                                                    | Professional MC, scripted and rehearsed                                                                                         |

Both poles are deliberate. The community pole publishes its reasoning far more (org blogs, CoCs, manifestos); the vendor pole's is equally intentional but under-documented - a sourcing asymmetry, not an intentionality difference. Never treat a vendor event as culturally lazy because it writes less about itself.
