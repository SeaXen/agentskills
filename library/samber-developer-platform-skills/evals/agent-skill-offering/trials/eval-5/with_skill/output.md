# Design: the `nb` skill content check (gate 3)

I read `agent-skill-offering` and its references (`ci-release-gates.md`, `skill-content-examples.md`). I didn't run or test any of this against your repo. I made a few assumptions, listed at the end.

## Root cause

Your version check (gate 2) proves only that someone bumped a string. The skill told 3.2 users to run `nb sync --legacy` for two months while it passed. The skill calls this out as rationalization #1: a script bumps the version and the content stays identical.

The release never ran the content check (gate 3), so nothing compared the skill's text with the binary.

## Where I disagree with product, and what I built instead

**1. Full coverage conflicts with the skill's own guidance.**
- `ci-release-gates.md` says "Never require coverage of the whole surface: that pushes the skill toward the command dump it should avoid." A bare "every command must appear" rule will turn `SKILL.md` into a flag-and-command table that goes stale on the next release.
- I still implement the requirement, in a way that doesn't hurt the skill:
  - `SKILL.md` stays job-shaped (when and why).
  - A generated `skills/nb/references/commands.md` lists every leaf command, one line each. The release step rewrites it, and CI fails if it is out of date.
  - The check scans the whole skill directory, so that file satisfies "every command appears".
  - Agents load that file only on demand.
- **Be honest with product about what this proves.**
  - Coverage proves a command is listed, not that the skill explains it.
  - The real protection is the stale direction: every command or flag the skill names must exist.
  - Product should accept that framing, because "complete coverage" alone would not have caught your incident.

**2. "Stop complaining about `--legacy`" is a misreading of the incident.**
- Per the issue, the migration section *tells agents to run* `nb sync --legacy`. That is a bug, not a deliberate "it was removed" note.
- Do not loosen the parser. First rewrite that section, e.g. "`nb sync --legacy` was removed in 3.0; use `<replacement>`". I don't know the replacement, so you need to supply it.
- After that, an allowlist entry may exempt only that exact invocation. The check proves the line says it was removed, and it fails if the entry rots (details below).

## Components

1. `nb commands --json`: a hidden subcommand that dumps the command tree. Click and Typer both make this easy.
2. `scripts/check-skill-content.py`: the check (Python 3.8+, stdlib only).
3. `scripts/skill-content-allowlist.json`: exemptions.
4. `skills/nb/references/commands.md`: generated by the check's `--write` mode.
5. Wiring: PR job, `make release`, and an artifact check.

### 1. Command dump schema

The dump is hidden, so it never lists itself.

```json
{
  "flags": [{"name": "--help", "takes_value": false},
            {"name": "--json", "takes_value": false}],
  "commands": [
    {"path": ["remote"], "leaf": false, "flags": []},
    {"path": ["remote", "add"], "aliases": ["a"], "leaf": true, "hidden": false,
     "help": "Add a remote.",
     "flags": [{"name": "--name", "takes_value": true}]},
    {"path": ["sync"], "leaf": true, "hidden": false,
     "help": "Sync with the remote.",
     "flags": [{"name": "--dry-run", "takes_value": false}]}
  ]
}
```

- `aliases` holds last-segment names only.
- `flags` includes short forms, e.g. a separate `-n` entry.
- `takes_value` lets the parser skip a flag's argument. Without it, `nb --env prod sync` would read `prod` as a subcommand.

### 2. The check

```python
#!/usr/bin/env python3
"""Gate 3: compare skills/ with the built `nb` binary. Python 3.8+, stdlib only.

Stale direction : every `nb ...` invocation in the skill must exist (command path and flags).
Coverage        : every non-hidden leaf command must appear, or be allowlisted with a reason.
Allowlist       : exact invocation, must sit on a line that says "removed"; fails when it rots.
Fail closed     : a broken `nb commands --json` or an extractor that finds nothing is an error.
"""
import argparse
import json
import re
import shlex
import subprocess
import sys
from pathlib import Path

BIN = "nb"
SKIP_FENCE_LANGS = {"text", "txt"}  # intentional pseudo-code blocks
SHELL_BREAKS = {"|", "||", "&&", ";", ">", ">>", "<", "2>&1"}
GLOBAL_FLAGS = {"--help": False, "-h": False, "--version": False}
# A removal notice must say so on the same line; wording is the evidence, not the allowlist entry.
REMOVED_WORDING = re.compile(
    r"\b(removed|no longer (exists?|available|supported)|does not exist|was dropped)\b", re.I)
FENCE = re.compile(r"^\s*(```+|~~~+)\s*(\S*)")
SPAN = re.compile(r"`([^`\n]+)`")


def load_surface(binary):
    try:
        out = subprocess.run([binary, "commands", "--json"], capture_output=True,
                             text=True, check=True, timeout=30).stdout
        return json.loads(out)
    except (OSError, subprocess.SubprocessError, ValueError) as exc:
        sys.exit("FATAL: cannot read `%s commands --json`: %s" % (binary, exc))


def build_tree(surface):
    children, flags, leaves = {(): {}}, {(): {f["name"]: f["takes_value"] for f in surface["flags"]}}, set()
    for c in surface["commands"]:
        canon = tuple(c["path"])
        flags[canon] = {f["name"]: f["takes_value"] for f in c["flags"]}
        parent = children.setdefault(canon[:-1], {})
        for name in [canon[-1]] + c.get("aliases", []):
            parent[name] = canon
        if c["leaf"]:
            if not c.get("hidden"):
                leaves.add(canon)
        else:
            children.setdefault(canon, {})
    if not leaves:
        sys.exit("FATAL: command tree has no leaf commands")
    return children, flags, leaves


def resolve(tokens, children, flags):
    """Return (leaf-or-group node or None, [problems])."""
    node, used, i, toks = (), [], 0, tokens[1:]
    while i < len(toks):
        tok = toks[i]
        i += 1
        if tok.startswith("<"):  # placeholder such as <command>: nothing to verify
            return None, []
        if tok.startswith("-") and len(tok) > 1:
            name = tok.split("=", 1)[0]
            used.append(name)
            known = dict(GLOBAL_FLAGS)
            for k in range(len(node) + 1):
                known.update(flags[node[:k]])
            if known.get(name) and "=" not in tok:
                i += 1  # skip the flag's value
        elif children.get(node):
            if tok not in children[node]:
                return None, ["unknown subcommand `%s` under `%s`" % (tok, " ".join((BIN,) + node))]
            node = children[node][tok]
        # else: positional argument of a leaf command
    valid = dict(GLOBAL_FLAGS)
    for k in range(len(node) + 1):
        valid.update(flags[node[:k]])
    return node, ["unknown flag `%s` for `%s`" % (f, " ".join((BIN,) + node))
                  for f in used if f not in valid]


def md_invocations(path):
    in_fence, marker, skip = False, "", False
    for n, line in enumerate(path.read_text(encoding="utf-8").splitlines(), 1):
        m = FENCE.match(line)
        if m:
            if not in_fence:
                in_fence, marker, skip = True, m.group(1)[:3], m.group(2) in SKIP_FENCE_LANGS
            elif m.group(1).startswith(marker) and not m.group(2):
                in_fence = False
            continue
        if "\u2717" in line:  # a line marked as a bad example
            continue
        if in_fence:
            cand = line.strip().lstrip("$").strip().rstrip("\\").strip()
            if not skip and (cand == BIN or cand.startswith(BIN + " ")):
                yield n, cand, line
        else:
            for span in SPAN.findall(line):
                span = span.strip()
                if span == BIN or span.startswith(BIN + " "):
                    yield n, span, line


def render_reference(surface):
    rows = sorted(c for c in surface["commands"] if c["leaf"] and not c.get("hidden"))
    out = ["<!-- Generated by scripts/check-skill-content.py --write. Do not edit. -->", "",
           "# nb command index", "",
           "Flags: run the command with `--help`. This file lists every command; "
           "SKILL.md says when to use which.", ""]
    out += ["- `%s %s`: %s" % (BIN, " ".join(c["path"]), c.get("help", "")) for c in rows]
    return "\n".join(out) + "\n"


def main():
    ap = argparse.ArgumentParser(description=__doc__)
    ap.add_argument("--bin", required=True, help="explicit path to the built binary")
    ap.add_argument("--skills-dir", default="skills")
    ap.add_argument("--allowlist", default="scripts/skill-content-allowlist.json")
    ap.add_argument("--reference", help="generated command index, inside the skill dir")
    ap.add_argument("--write", action="store_true", help="rewrite --reference (release step)")
    a = ap.parse_args()

    surface = load_surface(a.bin)
    children, flags, leaves = build_tree(surface)
    errors = []

    if a.reference:
        ref, want = Path(a.reference), render_reference(surface)
        if a.write:
            ref.write_text(want, encoding="utf-8")
        elif not ref.exists() or ref.read_text(encoding="utf-8") != want:
            errors.append("%s: out of date; run with --write and commit" % a.reference)

    allow = json.loads(Path(a.allowlist).read_text(encoding="utf-8"))
    removed = {(e["file"], e["invocation"]): e for e in allow.get("removed", [])}
    uncovered = {e["command"]: e for e in allow.get("uncovered", [])}
    removed_seen, covered, valid_seen = set(), set(), 0

    for md in sorted(Path(a.skills_dir).rglob("*.md")):
        rel = md.as_posix()
        for n, text, line in md_invocations(md):
            try:
                tokens = shlex.split(text)
            except ValueError as exc:
                errors.append("%s:%d: unparsable invocation `%s` (%s)" % (rel, n, text, exc))
                continue
            for k, t in enumerate(tokens):
                if t in SHELL_BREAKS:
                    tokens = tokens[:k]
                    break
            node, problems = resolve(tokens, children, flags)
            key = (rel, " ".join(tokens))
            if problems and key in removed:
                removed_seen.add(key)
                if not REMOVED_WORDING.search(line):
                    errors.append("%s:%d: `%s` is allowlisted as removed but this line does not "
                                  "say it was removed" % (rel, n, key[1]))
            elif problems:
                errors += ["%s:%d: %s" % (rel, n, p) for p in problems]
            else:
                if key in removed:
                    errors.append("%s:%d: allowlisted `%s` is valid again; drop the entry and "
                                  "fix the text" % (rel, n, key[1]))
                    removed_seen.add(key)
                valid_seen += 1
                if node in leaves:
                    covered.add(node)

    if valid_seen == 0:
        errors.append("extractor found no valid `%s` invocation in %s; check is blind"
                      % (BIN, a.skills_dir))
    for key in sorted(set(removed) - removed_seen):
        errors.append("allowlist entry %r matches nothing in the skill; delete it" % (key,))
    for leaf in sorted(leaves):
        name = " ".join((BIN,) + leaf)
        if leaf in covered:
            if name in uncovered:
                errors.append("`%s` is now covered; drop its 'uncovered' entry" % name)
        elif name not in uncovered:
            errors.append("command `%s` never appears in the skill; document it, regenerate the "
                          "index, or allowlist it with a reason" % name)
    known = {" ".join((BIN,) + l) for l in leaves}
    for name in sorted(set(uncovered) - known):
        errors.append("'uncovered' entry `%s` is not a command any more; delete it" % name)

    if errors:
        print("\n".join("FAIL " + e for e in errors), file=sys.stderr)
        sys.exit(1)
    print("skill content OK: %d commands, %d valid invocations" % (len(leaves), valid_seen))


if __name__ == "__main__":
    main()
```

Known limits:
- Multi-line shell continuations are checked only on the line that starts with `nb`.
- Prose mentions outside backticks are ignored.
- It checks invocations, not behavior.

### 3. Allowlist

```json
{
  "removed": [
    {"file": "skills/nb/SKILL.md", "invocation": "nb sync --legacy", "removed_in": "3.0.0",
     "reason": "Migration section tells agents the flag is gone."}
  ],
  "uncovered": [
    {"command": "nb completion", "reason": "Human shell setup, never an agent job."}
  ]
}
```

The `removed` entries follow these rules:
- **Exact match:** an entry matches one exact invocation in one file, never a flag everywhere.
- **Wording proof:** the same line must say "removed" or similar, so an entry can't excuse an instruction to run it.
- **Revival:** if `--legacy` returns to the CLI, the check fails and demands the entry be deleted.
- **Dead entry:** if the text disappears from the skill, the check fails and demands the entry be deleted.

The `uncovered` entries need a reason. They fail the same way when stale, and the report lists them so reviewers see the exemption count grow.

### 4. Wiring

**Pull requests** run on any change to code or `skills/`. The release job runs the same step before the tag exists.

```yaml
- run: pip install -e . && python -m build
- name: Skill content matches built nb
  run: |
    python3 scripts/check-skill-content.py --bin "$(command -v nb)" \
      --skills-dir skills --reference skills/nb/references/commands.md
- name: Wheel ships the skill
  run: unzip -l dist/*.whl | grep -E 'skills/nb/SKILL.md'
```

The wheel only ships the skill if `pyproject.toml` includes it. With hatch that is `[tool.hatch.build.targets.wheel.force-include] "skills" = "nb/skills"`, or your backend's equivalent.

**`make release VERSION=x.y.z`** runs these in order:
1. `scripts/check-skill-version.py $(VERSION) --write ...` (your existing version step).
2. Build `nb` with release stamping, to an explicit path.
3. `scripts/check-skill-content.py --bin ./dist/nb --reference ... --write`, then rerun it without `--write`.
4. `git diff --exit-code` to catch any file the bump forgot.
5. Commit, tag, push.

Order matters. A failure at the tag, or after the PyPI upload, leaves a published stale release.

**Optional:** add the changed-surface gate (gate 4). It fails a PR that changes `nb commands --json` output without touching `skills/`, unless a `skill-unaffected` label is set.

## Verification (mutation tests)

The setup passes only if each of these fails the way described:

| Mutation | Expected result |
| --- | --- |
| Restore the old migration text (no allowlist entry) | Fails: unknown flag `--legacy` for `nb sync`. This would have failed the 3.0 release. |
| Add the allowlist entry but keep "run `nb sync --legacy`" | Fails: line does not say it was removed. |
| Reword to "removed in 3.0" and keep the entry | Passes. |
| Re-add `--legacy` to the CLI | Fails: allowlisted flag is valid again. |
| Add `nb foo` to the CLI | Fails: never appears; regenerate the index. |
| Make `nb commands --json` exit 1 | Fails closed (FATAL). |
| Point the check at a skills dir with no `nb` invocations | Fails: extractor is blind. |

The check must run against the built wheel's `nb`, not whatever `nb` is on `PATH`.

- **Release mechanism:** is it a manual tag, release-please, or CI on tag push? I assumed a `make release` style flow.
