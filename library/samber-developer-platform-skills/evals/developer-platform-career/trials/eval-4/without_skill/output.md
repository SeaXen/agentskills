Postman cert first, apiMasters second only if its syllabus checks out, bootcamp never. None of the three is what gets you hired fastest. Shipping something developer-facing is.

**Why certs are weak here**
- Hiring managers for API PM roles screen for developer-facing evidence. That means API, platform, or integration work, plus DX judgment.
- Your gap is "no developer-facing product in four years." A certificate doesn't close that gap. A shipped API or integration does.
- I haven't verified current prices or syllabi for apiMasters or the Postman cert. Check both before paying.

**Ranking**
1. **Postman cert.** It is cheap or free, and takes about 1–2 weeks. It shows you can call APIs, read specs, and write tests. Do it, but expect little weight on a CV.
2. **apiMasters.** Buy it only if the syllabus covers PM topics: API lifecycle, versioning, developer adoption, monetization, deprecation. Skip it if it is mostly design and tooling, which overlaps Postman. Ask for the syllabus before paying.
3. **PM bootcamp.** Skip it. You have four years of PM experience, so it teaches what you already know. It is the worst use of the budget.

**What gets you hired faster**
1. **Move internally in the next 3–6 months.**
   - Your merchandising features already sit on internal APIs: catalog, pricing, inventory, supplier feeds.
   - Ask to own one, or an integration with a partner or supplier. Internal developers are API customers.
   - This is the only item that gives you real API PM experience on your CV.
2. **Track API product metrics on that work.**
   - Time to first call, integration count, error rate, and support tickets per integrator.
   - These numbers are your interview stories.
3. **Build two public artifacts (2–3 weekends).**
   - An API product teardown of a public API. Cover its onboarding, docs, versioning, and pricing.
   - A short spec or OpenAPI file for a retail API you would build.
4. **Learn API fundamentals.**
   - REST, auth (OAuth2, API keys), pagination, rate limits, versioning, OpenAPI.
   - This is the Postman cert content, so step 1 of the ranking covers it.

**Budget (you don't have to spend all 2,000 EUR)**
- Postman cert: about 0–100 EUR. Confirm the price.
- apiMasters: spend only after you've checked the syllabus.
- One conference ticket, such as Nordic APIs or apidays, if it fits the budget. It gives you networking with API PMs and hiring managers.
- Leave the rest unspent. Unspent budget costs you nothing when it expires.

**12-month timeline**
- Months 0–1: Postman cert, API teardown, 5 informational chats with API PMs.
- Months 1–6: take on an internal API or integration at Brightloom and track the metrics.
- Months 6–12: apply, with the shipped work and metrics as your lead story.
