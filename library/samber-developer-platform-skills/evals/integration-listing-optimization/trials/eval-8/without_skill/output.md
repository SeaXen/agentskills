## (a) Tagline rollout to Shopify and Atlassian

**Evidence is too weak to call it a win.** Installs are up 1.6% nine days after the swap.
- There is no stated baseline. Organic was flat since spring, so the comparison needs weekly install counts from before the swap.
- A 1.6% move is likely noise. Illustration: at about 200 installs in nine days, normal random variation is around ±7%, so 1.6% sits well inside it. Check this against our real count.
- Other changes in the same window (releases, seasonality, campaigns, reviews) could explain it.

**Why roll out anyway.** A tagline swap is cheap and reversible. The risk is acting on a false read, not the swap itself.

**Plan, this week:**
1. Record the 8-week pre-swap weekly installs and views on HubSpot, Shopify and Atlassian.
2. Ship the new tagline to Shopify first, then Atlassian a week later, so the two don't confound each other.
3. Keep the old tagline text on file for a revert.
4. Re-read at 4 weeks. Call it a win only if the change in view-to-install conversion (not raw installs) clears normal week-to-week variation.

**Caveat:** the HubSpot audience may differ from the Shopify and Atlassian audiences. The tagline may not transfer.

## (b) $8K/month standing paid placement

**Why not standing spend now:**
- The case rests on "organic has been flat." That is a reason to test paid, not proof that paid will return its cost.
- We have no measured view-to-install rate or cost per install to size the spend against.
- A standing commitment removes the decision point. A pilot keeps it.

**Which marketplace sells placement.** This is from my own knowledge and I have not verified it:
- **Shopify App Store:** has paid search and category placement. It is the most likely fit.
- **HubSpot App Marketplace and Atlassian Marketplace:** I'm not aware of a self-serve paid placement product on either. Confirm with each partner manager before budgeting.

**Proposed pilot:**
- **Budget:** $2K/month for 2 months, about $4K total, on the one marketplace that sells it. This is 25% of the first two months of the standing ask.
- **Success test, set before launch:** cost per install must be below the value of an install. Use first-year revenue per install times margin.
- **Kill rule:** stop if cost per install is above the threshold at week 6.
- **Decision at week 8:** scale toward $8K/month only if the test passed.
