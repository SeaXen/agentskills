## 2. Tier, format, proctoring, levels

**Launch (conference day): completion badge, "Pellmont Associate".**

**Conditional (Plan B): skill badge, same "Associate" label.**

## 4. Build plan

## 5. Integrity plan (Plan B only)

- **Cut score:** a panel of about 6 senior users writes the minimum end-state checks from pilot solutions. This is modified Angoff adapted to end-state checks. The checker enforces those checks, not a percentage.
- **Equating:** rotate variants. Pass rate per task flags a leak.
- **Proxy sitting:** the named threat if employers screen on it. The countermeasure is the live call on a sample of passes. A failed or refused call suspends the credential until a supervised retest, with appeal.
- **Privacy:** no recordings or face data by default. A privacy review is needed if you change that.
- **Leak runbook:** pull the variant, switch to a reserve variant, write a replacement.

## 6. Renewal, versions, retirement

- Stamp the badge with the supported Pellmont major version. No expiry.
- On a new major version, offer a 30-minute delta task. The older badge stays valid and labelled while that version is supported.
- Run checkers against each release. The re-alignment window in weeks is self-set once the release cadence is known.
- **Retirement:** announce an exam version in advance and honour holders until their own expiry. If the program ends, keep verification live for a stated period (self-set: 3 years) and honour every credential.
