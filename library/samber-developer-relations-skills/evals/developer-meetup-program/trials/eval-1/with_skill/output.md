## Why "cap RSVP at 60" is the wrong fix

You're solving the wrong variable. The 640€ waste came from ordering food off the RSVP count, not from the RSVP count being too high. Capping RSVPs at room capacity doesn't fix that — it just guarantees a smaller version of the same mistake, because show-up rate stays below 100% regardless of the cap:

| If show-up rate is... | ...and RSVP cap = 60, attendance = |
|---|---|
| CNCF baseline (70%) | 42 — room 1/3 empty |
| Friend's folklore (50–60%) | 30–36 — room half empty |
| Your own last month (35%) | 21 — room two-thirds empty |

Every one of these under-fills a 60-seat room. You'd still be ordering food for a number nobody hits.
