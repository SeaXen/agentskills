## Reminder cadence

For a capacity-limited, sponsor-hosted meetup, this sequence covers RSVP-conversion, headcount-for-catering, and day-of no-show reduction:

| When | Channel/audience | Content |
|---|---|---|
| **Tomorrow (T-launch)** | Public post | Announcement above |
| **Once Ana confirms (this week)** | Public post | Speaker/topic reveal — second touchpoint |
| **T-3 days** | RSVP'd list | Speaker + topic recap, address/directions, "bring a friend" nudge |
| **T-2 days** | Internal only | Headcount check-in with Vantix for pizza/beer order — lock the number before the venue needs it |
| **T-1 day** | RSVP'd list | Logistics reminder: exact address, doors 18:30, parking/transit note |
| **Morning of (T-3h)** | RSVP'd list | Short "see you tonight" + map link — this is the one that actually kills no-shows |
| **T+1 day (after)** | Public post | Thanks + photos + save-the-date teaser for the next one — compounds the series instead of letting it evaporate |

Two things worth flagging since this is a **recurring** series sponsored by a company hosting in their own office:
- Vantix will want the headcount reminder (T-2 days) for the catering order — don't skip it, it's the one with a real deadline attached.
- Record Ana's talk if she's comfortable with it — a recurring meetup's recordings become your best recruiting material for getting the *next* speaker to say yes.
