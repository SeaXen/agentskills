**Verdict: half right. Launch plan solid, labels wrong. Fix labels before event 1 or graduation never triggers.**

**What works**

- Funded pilot before volunteers exist is normal. Vendor-run meetups (AWS, HashiCorp, Datadog user groups) all started this way.
- Two engineers delivering talks + roadmap update gives real value to attendees in phase one. Fine as launch content.

**What breaks the progression**

- "Organizer" title is wrong for someone who only books a room. Real organizers pick topics, invite speakers, set agenda. Title with no matching job gives that person no reason to stay engaged, and gives you nothing to hand off later.
- Calling it a "Corvex User Group" run by "organizers," when Corvex runs it end to end, is a label mismatch. If a local attendee notices and posts about it, you take reputation damage in the exact four cities you're trying to seed.
- Plan names a destination ("graduate to independent group") but has no mechanism moving ownership from Corvex to local people over time. Without that, all four cities stay Corvex roadshows indefinitely — cost never drops, "graduate" never fires.

**Fix, before invites go out**

1. Rename the local role: "local host," not "organizer." Match title to task now; upgrade title when task upgrades.
2. Rename the event framing: "Corvex-hosted meetup, in partnership with [local host]" — not an implied independent user group. Disclosed vendor-hosted is a known, accepted pattern; undisclosed is the risk.
3. Recruit for actual signal, not just room-booking availability. Pull from people already active in your Discord/forum/support queue, people already running adjacent local meetups, or top usage/power users. Room-bookers have no reason to keep the group alive after Corvex leaves; these people do.
4. Set graduation milestones now, reviewed after each event, not decided later:
   - Event 2 — local host picks one talk topic.
   - Event 3 — local host recruits one non-Corvex speaker.
   - Event 4 — local host co-runs the agenda; a Corvex engineer is one speaker, not the whole show.
   - Event 6 — local host runs the event; Corvex sponsors only.
5. Track one signal per event: did the local host do anything beyond logistics this round? If still no by event 3, the program is stalled — flag it to leadership then, not after six events of spend.
