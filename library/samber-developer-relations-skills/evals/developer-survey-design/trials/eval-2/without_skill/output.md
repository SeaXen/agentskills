**Headline**

70% of Lanternfish Users Who Use Both the CLI and the Web Console Prefer the CLI

**Supporting sentence**

In the Lanternfish Developer Survey 2026, 70% of the 1,480 respondents who use both the Lanternfish CLI and the web console said they prefer the CLI; the 2,140 responses came from readers of our newsletter and docs and members of our Discord community.

**Why I didn't use the CEO's version**

- **"70% of developers" overstates the finding.** The sample is self-selected from newsletter, docs banner and Discord, which are our most engaged users. It says nothing about developers in general, and probably not about all Lanternfish users either. Those channels likely lean toward CLI fans, so the real figure for our whole user base could be lower.
- **The subgroup is "uses both."** The 70% covers only the 1,480 who use both tools. The other 660 respondents aren't in that number, so the headline has to say so.
- **"±2.3%" is arithmetically right but misleading.** It matches a 95% margin for n=1,480, but that formula assumes a random sample. For a self-selected sample it implies precision we don't have, and regional weighting would change it anyway. I left it out. If the press team needs a figure, "±2.3 percentage points, assuming a random sample" is the honest wording, and I'd still skip it.

**On weighting by region**

- Weighting is fine as a robustness check, but it doesn't fix self-selection. It only fixes the regional mix, and only if CLI preference differs by region.
- Don't weight to "what we reckon." Use a real distribution, such as account billing country or telemetry.
- Run both versions. If the weighted number is within a point or two of 70%, publish the unweighted number and add "results were consistent when weighted by region."
- If the weighted number is materially different, lead with the weighted one and add "weighted by region to match Lanternfish's user base." Then drop the ±2.3 and say how weighting was done.
- Don't weight just because the result looks off. Choose the method before you see which number it produces.

**If the CEO insists on a stronger lead**

"7 in 10 Lanternfish users who use both the CLI and the web console prefer the CLI, survey finds" is the strongest version I'd stand behind. The sentence about how respondents were recruited has to stay in.
