**Request: 0.5 FTE — Error Documentation**

**The cost of the status quo**
Support handles roughly 1,400 tickets a quarter. Industry estimates put the cost of handling a ticket between $15 and $50, with $28 the commonly cited midpoint — call it $39,200 a quarter, or $157,000 a year, in support labor. A fixed slice of that volume is the same 20 errors, resolved the same way, every time, because nothing at the point of failure tells the user what to do.

**The fix**
Hire 0.5 FTE to own error documentation end to end: one page per error — cause, fix, prevention — linked directly from the error message itself and from the support macros used to close these tickets today. Documentation tied to an exact error string deflects better than general help content, because the user can search the literal text of the error; well-run self-service programs see 60-70% deflection on the issues they cover.

**What it's worth**
Assume, conservatively, that the top 20 errors account for 30% of the 1,400 quarterly tickets — 420 tickets, $11,760 a quarter, $47,040 a year. Documentation alone, at a 60-70% deflection rate, recovers $28,200-$32,900 of that annually. Compare that to the fully loaded cost of 0.5 FTE to see the payback period; either way, the number above is a floor, not a ceiling, since the 30% figure is an assumption, not a measurement (see note below).

**Objective**
Cut ticket volume on the top 20 recurring errors by 60-70% through documentation by Q3, trending to zero as the highest-volume errors get root-cause fixes alongside the docs. Track weekly, by error code, against today's baseline.

**Ask**
Approve 0.5 FTE, starting [date], to identify the top 20 errors from ticket data, write and ship the docs, wire them into the error flow, and report deflection monthly.
