| Pillar | % | Budget | Rationale |
|---|---|---|---|
| Documentation & Learning Content | 30% | $75,000 | Primary discovery channel — individual devs self-serve via docs, API reference, sample games, learning paths |
| Community & Support | 20% | $50,000 | Discord/forums/office hours keep free-tier devs engaged long enough to reach a shipped project |
| Events, Conferences & Game Jams | 18% | $45,000 | GDC, indie showcases, jam sponsorships — discovery plus the credibility that gets a studio's attention |
| Studio Success & Upgrade Enablement | 12% | $30,000 | Case studies, migration support, dedicated outreach triggered at ship — targets the actual conversion moment |
| Creator & Influencer Partnerships | 12% | $30,000 | YouTube/Twitch devs building visibly with the SDK — amplifies top-of-funnel discovery |
| Tooling, Samples & Starter Kits | 5% | $12,500 | Open-source templates/plugins that lower time-to-first-build |
| Program Ops, Analytics & Contingency | 3% | $7,500 | Attribution tracking (which individual → which studio upgrade), buffer |
| **Total** | **100%** | **$250,000** | |

Logic: your funnel has two distinct conversion events — individual activation (top-heavy: docs/community/creators, 62%) and studio-level upgrade after shipping (targeted: events + success enablement, 30%) — with ops/tooling as the remainder. If four people are stretched thin, Docs + Community + Studio Success are the three that should never get cut; Events and Creator budget are the ones to flex down first if headcount slips.
