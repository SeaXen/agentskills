# Verdict

Set measurable but comp-unsafe. Three raw activity counts plus one outcome metric with no attribution method. Every metric pays volume, none pays quality or activation. Biggest single risk: per-person attributed signups tied to comp.

# Per-target check

**6 blog posts/month each**
- 24 posts/month team-wide = one per business day. Content-farm volume.
- Deep CI-orchestration post (reproducible pipeline, real benchmark) costs 3-5 days done well. At 6/month, each gets under 1 day. Quality collapses by design.
- No quality gate: filler pays same as flagship.
- 4 writers chase same keywords = SEO cannibalization.
- Who reviews 24 posts/month? Editorial capacity undefined.
- Replace with: 1-2/person/month, editorial pass required, each post measured on engaged reads + assisted signups at 90 days.

**40 community messages/week each**
- Count rewards spam. Communities flag drive-by promo fast. Damages brand you pay to build.
- Replace with: median first-response time, threads resolved with confirmed answer, accepted answers, repeat contributors converted.

**20 GitHub issues closed/month each**
- "Closed" gameable: stale-close, duplicate-close, wontfix, cherry-pick easy tickets.
- Advocates don't ship fixes, engineering does. Closed ≠ resolved.
- Replace with: triage SLA (90% labeled + routed + repro requested under 24h), reopen rate under 10%, community PRs merged.

**500 attributed signups/quarter each**
- Worst metric in set. Individual attribution of lagging multi-touch outcome = quarterly credit fights once comp attaches.
- Content compounds late. Post written week 2 converts month 4. Quarter-bound attribution punishes exactly the work that works.
- Self-reported attribution + comp = advocates coaching users to name them. Happens every time.
- Equal quota ignores lanes. Writer ≠ speaker ≠ community manager.
- 2,000/quarter team = ~22/day. At 1-3% content-to-signup conversion needs 700-2,200 targeted visitors/day. Check real traffic before trusting number.
- Replace with: team-level activated signups only. Activated = repo connected + first successful build within 14 days.

# Structural gaps — fix before comp attaches

1. Attribution method undefined. Define now: UTM discipline, "how did you hear about us" field, CRM linkage. Individual level: skip entirely.
2. Zero team metric. All four individual = zero-sum competition, keyword overlap, credit claims.
3. No activation layer. Nothing measures whether signups use product. For adoption-driven company, activated usage is real north star.
4. No baselines. 6/40/20/500 all round = invented. Derive each from current run rate ±20%.
5. No definitions. "Post", "message", "closed", "attributed" all undefined. Comp disputes come from undefined units.

# Coverage gaps — work not measured

1. Docs/DX. For dev tools docs drive activation more than blog. Absent.
2. Events. DevConf sponsorship exists in your world. Talks and workshops move CI-tool signups. Absent.
3. Product feedback. Advocates = highest-bandwidth community-to-product signal. Not comped = skipped under quota pressure. Add insights or RFCs delivered per quarter.
4. Integrations/OSS. CI tools spread through integrations and community contributors. Absent.
5. Distribution. 24 posts nobody promotes = tree in forest. No one owns launches, SEO infra, newsletter.

# Context flags — from prior context, private

- Pricing change pending announcement. If it lands inside target quarter, signup comp pays or penalizes on pricing effect, not advocate work. Re-baseline after it settles.
- Flagship case study still uncleared by customer legal. Content treadmill collides with review latency. Plan anonymized variants.
- Workload math: 24 posts + 160 messages/week + 80 issues/month consumes all four advocates. Zero hours left for work that produces signups. Set fights itself.

# Restructured set

- ~50% team outcome: activated signups/quarter. One number, whole team.
- ~30% individual inputs, quality-gated: 1-2 posts/month passing editorial; community first-response median under 24h; GitHub triage 90% under 24h; each advocate one specialty lane (docs, events, OSS, video) with own lane metric.
- ~20% judgment: manager + peer review. Numbers lie, humans read quality.
- Guardrails tracked, never comped: reopen rate, sentiment and spam reports, activation-rate floor, cannibalization audit.
- Payout 80-120% band, no cliffs.
