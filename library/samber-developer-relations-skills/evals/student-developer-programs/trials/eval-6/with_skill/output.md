## Component rules applied

**Student offer**
- **Credits:** give capped usage credits, no card at signup. Your free tier is a card wall, so this is what makes the offer valuable.
- **Cap:** set it so 100 students at the cap is a number you can afford. For example, $20 each is $2k worst case. This figure is self-set, so choose your own.
- **Verification:** never by email domain alone.
  1. Check whether you can gate on a student's existing GitHub Education verification, as MongoDB does.
  2. If you can't, use a paid verified-student service.
  3. If you can't afford that, review documents by hand, capped at 10 students a week.
  4. Don't plan on being accepted as a GitHub Student Developer Pack partner.
- **Abuse:** no resellable keys or vouchers. One account per student. Watch for mass accounts and workloads unrelated to study, and revoke on abuse. GPU cost makes farming expensive, so set rate limits from day one.
- **Expiry:** credits expire at the verified end date, and you re-verify yearly. Before expiry, prompt the student to add a personal or work email.
- **Bridge:** a discount window after graduation. For reference, JetBrains gives former students 40% off for two years. Your pay-as-you-go model suggests a credit or discount on the first paid usage within a fixed window. The level is **blocked** until your pricing owner confirms it.
- **Age, pay and visa rules:** 18+ post-secondary students only. No cash and no work assigned. The offer is an access perk, so it creates no F-1 work issue. Anyone under 18 gets a separate design with schools and parents, not this one.

**Faculty kit (later)**
- **Accounts:** instructor-managed class accounts, no card, same credit cap.
- **First kit:** one course-sized assignment, for example calling the inference API in batch and measuring latency and cost, with an automatic check and slides. Not a full course.
- **Solutions:** go to verified instructors only, in an access-gated place, never a public repo.
- **Freeze:** the kit is frozen per term. Ship breaking product changes between terms.
- **School review:** expect IT, privacy and accessibility review, and an EU or UK data processing agreement. Use no classroom data for marketing.
