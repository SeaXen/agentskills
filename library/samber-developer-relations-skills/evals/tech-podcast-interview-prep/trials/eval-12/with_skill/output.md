Recording's the disclosure gate (step 10) — done. What's left lives in the skill's **promotion loop** (step 12) and **measurement** section, and most of it has to happen *before* the episode drops, not after. A tweet on publication day alone leaves nearly everything else in the loop on the table.

**Now, during the three-week wait**

- **Send the host a promo kit unasked**: third-person 2-line bio, a high-res headshot, the exact links you want referenced, and 3-5 candidate timestamps/quotes. Hosts rarely ask for this — sending it anyway shapes how you get framed and buys goodwill for a repeat invite.
- **Ask the host for the raw clip files** and, if the show does one, the transcript. You'll need both for week 1 and evergreen below.
- **Set up attribution before publication day**, not after — you can't retrofit it:
  - If you said a vanity URL or a spoken code on air, get that URL live now.
  - If you have a signup form, add the show as an option in "where did you hear about us."
  - **Capture your branded-search / direct-traffic baseline now** — the skill's comparison window is 7-14 days post-publication vs. baseline, and you need the "before" number in hand before the episode exists publicly.
- Pick which single **sound bite** the publication-day post will carry. "I was on this show" with a bare link is the failure mode the skill calls out explicitly — build the post around one liftable line + the link instead.

**Publication day**

- One post per surface you own (blog, LinkedIn, newsletter, community — not just the tweet), each anchored on that one sound bite, not a repeat of the same generic announcement.
- Tag the host/show, thank them publicly — it's low-cost and feeds the repeat-invite signal below.
- Run any written copy through a humanizer pass before it goes out — first-draft promo copy reads as marketing and undercuts the credibility the episode just earned.

**First week**

- Reply to comments wherever the episode surfaces (YouTube, the show's own platform, HN/Reddit if it lands there) — including the critical ones.
- Add the episode to your project's README, docs, or a talks/media page. This is the step guests skip most, and it's the one that keeps paying off after the feed moves on — it's also the machine-readable record AI assistants will crawl and cite later.

**Evergreen (once the transcript exists)**

- Turn the strongest ~10 minutes into a written post using the transcript as the draft, cross-linked with the episode. Highest-value, most-skipped step in the whole loop.

**Measurement — check in this order, not by whichever number shows up first**

1. Vanity URL / spoken code — cleanest per-episode attribution, if you set one up above.
2. Signup-field "where did you hear about us" — strong, self-reported.
3. Branded search + direct traffic lift, 7-14 days vs. baseline — directional, worthless if another launch overlaps that window.
4. Stars / installs / docs traffic in the same window — noisy.
5. Host-reported downloads and clip views — reach, not impact. Don't lead with this one even though it arrives first.
6. Repeat invitation, or a referral to a neighboring show — slowest signal, and the real return. If you'd like more podcast appearances, this is the moment to ask the host (informally, no pressure) whether they know other shows that'd be a fit — your story bank and sound bites are already built and reusable, so a second booking costs you almost nothing incremental.
