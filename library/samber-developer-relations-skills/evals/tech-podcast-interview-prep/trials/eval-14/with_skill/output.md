Kill "send all questions" plan. Skill's own rule: full question list → memorized, robotic answers live. Ask for these 5 things instead on Monday:

1. **Opening question only, pre-agreed** — not the full list. Lock down the literal first question so you can write and rehearse *that one* answer word-for-word (punchline first, ~30 sec, self-contained — survives a clip with no intro context). Rest stays bullets, not scripts: a memorized script that gets interrupted has nothing underneath it.
2. **Story-first or tips-first** — which does the host prefer. Decides whether you prep a war story or a practical how-we-do-it angle.
3. **Audience today** — hands-on engineers, staff/architects, EMs, or buyers. Ask if it shifted since early 2025; a returning guest can't assume the same room.
4. **Booked topic, in her words** — "the scheduler" isn't an angle. Get what she's actually pitching: an update, a deep-dive, a comparison against something newer.
