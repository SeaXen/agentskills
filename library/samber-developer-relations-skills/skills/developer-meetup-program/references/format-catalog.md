# Format catalog and run of the evening

Contents: format menu · recurring effort per format · run of a standard evening · first edition · step-up formats.

## Format menu

The ranking lives in `SKILL.md` Step 3 - efficiency: `anchor + lightning > study group > two-talk classic > open space > hands-on workshop`. This table extends that menu with five variants; each sits beside the ranked format it resembles, so read the recurring-effort column against that order rather than as a second ranking.

| Format                     | Shape                                       | Recurring effort                                | Best for                                    |
| -------------------------- | ------------------------------------------- | ----------------------------------------------- | ------------------------------------------- |
| Anchor + lightning         | 1 × 25 min + 3 × 5 min                      | One speaker, plus volunteers from the room      | Growing a speaker bench                     |
| Lightning night            | 5-8 × 5 min                                 | Many low-stakes asks, no anchor to confirm      | Restarting a stalled group; end of year     |
| Ignite                     | 5 min, 20 auto-advancing slides at 15s each | Same asks as lightning, higher prep per speaker | A group that already enjoys lightning talks |
| Demo night / show-and-tell | 6-10 min per project, no slides required    | Attendees present their own work                | Maker-heavy rooms, hobbyist audiences       |
| Study group                | Group works through a book, course or spec  | No external speaker, near-zero prep             | Small or new groups, quiet months           |
| Two-talk classic           | 2 × 20-30 min + Q&A                         | Two speakers per edition, every edition         | Established group with a full pipeline      |
| Panel                      | 3-4 guests, one moderator                   | One good moderator, four calendars              | Contentious topics; never as a default      |
| Live podcast / interview   | 30-40 min on stage, recorded                | One guest, one host, plus editing after         | Groups with an existing media surface       |
| Open space                 | Attendees propose sessions on the night     | None                                            | Rooms where people already know each other  |
| Hands-on workshop          | 60-90 min, laptops required                 | One facilitator, a day or two of preparation    | Deep engagement, small rooms, tool adoption |

Two failure patterns worth naming:

- A panel booked because no speaker was found: four people saying little beats one person saying something - untrue.
- A workshop scheduled monthly by a two-person team: prep cost breaks the cadence within a quarter.

## Run of a standard 2-hour evening

| Time  | Block                                | Notes                                                                                                |
| ----- | ------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| 18:30 | Doors, food, informal networking     | Nothing starts on time; plan for it rather than fighting it                                          |
| 19:00 | Welcome, 5 min                       | Group intro, code of conduct in one sentence, first-timers wave, sponsor thanks, next date announced |
| 19:05 | Talk 1, 25 min + 5 min Q&A           | The stronger or more accessible talk goes first - latecomers are still arriving                      |
| 19:35 | Break, 15 min                        | Real break. This is where people meet each other; cutting it to save time defeats the evening        |
| 19:50 | Talk 2 or lightning slots, 25-30 min |                                                                                                      |
| 20:20 | Wrap, 5 min                          | Feedback QR code on screen, call for speakers, call for venues, next date again                      |
| 20:25 | Networking until the venue closes    | Announce the hard stop; venues have one                                                              |

Announce the next date twice from the stage. The single cheapest retention mechanic available is the room leaving with a date in their calendar.

## First edition

Strip it to the minimum viable event: one speaker, one room, drinks, a fixed date for the second edition announced from the stage. Ten to fifteen attendees is a real start - CNCF's active-chapter bar is a quarterly event with more than ten people through the door. Do not open with a two-track afternoon.

## Step-up formats

When the monthly evening is consistently full, the next rung is a half-day: roughly four hours, multiple speakers, catering breaks, and real sponsorship - and at most once a quarter, alongside the normal rhythm rather than replacing it. That is where the effort curve changes: full-day and multi-day production is a different discipline, covered by samber/dev-event-organizer-skills.
