# Failure modes

| Failure              | What it looks like                                                    | Fix                                                                                         |
| -------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Host-time slot       | 14:00 Paris slot, US West users asleep                                | Anchor in audience time; overlap method; push the cost onto staff when the overlap is empty |
| Goodwill rotation    | Engineers "invited", gone by week four                                | Written manager agreement, session cap, backup per session, counted in reviews              |
| Cap arithmetic       | Weekly sessions promised with three engineers                         | Engineers ≥ sessions per month + 1 before committing to the cadence                         |
| Support shadow       | Customers bring account and billing issues live                       | Scope card with destinations, read at the start                                             |
| Live debugging       | Session spent inside one user's cluster, secrets on screen            | No-access rule; minimal reproduction instead                                                |
| Disappearing slot    | Drop-in cancelled whenever the queue is empty; users stop trusting it | Hold drop-in slots; cancel only livestreams, and only publicly                              |
| Silent cancellation  | Calendar active, nobody running it                                    | Public pause or closure post on every channel used for promotion                            |
| Answer and forget    | Same three questions every month                                      | Docs ticket per question family on second sighting; labelled and counted                    |
| Lost requester       | Feature request logged, nobody can tell the asker it shipped          | Copy the handle into the feedback record with consent                                       |
| Viewer vanity        | Report counts recording views                                         | Count distinct askers and docs fixes                                                        |
| Recording by default | Faces and configs published without notice                            | Per-format policy, notice script, captions, pre-publication review                          |
| Launch-weekly        | Weekly live slot before anyone has asked anything                     | Demand gate; async thread first                                                             |
| Borrowed benchmark   | "3 askers per session" quoted to leadership as an industry figure     | Quote only sourced figures externally; call baselines "our target"                          |
