## This skill's own baselines

Defensible starting points, internally consistent with the rest of this collection. Present them as adjustable, never as standards.

Population figures stop where the published sources stop: language, sector or platform level. A number for anything narrower is your own arithmetic, and the map has to say so.

| Baseline                                 | Value                                                         | Why this number                                                                                                                                                |
| ---------------------------------------- | ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dimensions per cut                       | exactly two                                                   | a two-axis grid stays legible in a meeting; a third multiplies cells past what a team can staff                                                                |
| Segments per map                         | three to five                                                 | two usually means the audience was not cut; six means none gets served                                                                                         |
| Funded ranking shape                     | one primary, one secondary, one written anti-segment          | the anti-segment is the only part that actually stops work                                                                                                     |
| Evidence floor                           | 5-10 independent data points from a consistent group          | a customer-research convention - treat it as a practice norm, not a measured floor                                                                             |
| Share of funded segments above the floor | at least half                                                 | arbitrary; it exists to stop a whole map being hypotheses                                                                                                      |
| Scoring scale                            | 1-3 or high/medium/low                                        | coarse scales move the argument off the score and onto the segment                                                                                             |
| Map length                               | two pages                                                     | a map nobody re-reads decides nothing                                                                                                                          |
| Review horizon                           | one quarter, plus named early-re-read triggers                | matches the planning cadence most of this collection assumes                                                                                                   |
| Candidate-cut ordering                   | ecosystem cut, then buying-mode, then workload, on efficiency | reasoned from the research each cut needs before anyone can be placed on one side of the line, and meant to be re-ranked against the data a team already holds |
| Segment ranking arithmetic               | value divided by effort, not summed with it                   | a summed score lets a segment win on breadth while its prerequisite artefact list is longer than the horizon                                                   |

## How to re-verify

1. Re-fetch the survey waves before quoting a figure - SlashData and Stack Overflow publish annually, and a two-wave-old number invites the wrong objection.
2. Re-read RedMonk's own caveat paragraph in the current run before quoting a tier.
3. State the checked date next to every external figure inside the map itself, not only here.
4. Replace any sourced row above with a first-party measurement as soon as one exists; measured beats estimated at every review.
