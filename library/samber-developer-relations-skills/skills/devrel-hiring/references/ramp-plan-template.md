# 30-60-90 ramp plan template

Contents: the three-phase structure · the artefact milestone at each phase · the early-warning check.

DevRel has no published, field-wide ramp benchmark the way sales has quota-attainment surveys - this template is this skill's own working structure, built from the same artefact logic devrel-career uses for entry: coding depth is role-dependent, but shipping something real, in public or internally, is universal.

## Day 0-30: use the product like a developer would

- Onboard onto the product as a real user, on the same path a developer prospect would take.
- Meet the developers already using the product, and the internal teams (product, support, docs) whose work this role touches.
- Ship a friction log: the concrete points where onboarding, docs, or the API confused a fresh user, with severity and a proposed fix per point.
- Certification/product-knowledge gate: the new hire can explain the product's core workflow to a stranger without notes.

## Day 31-60: ship the first real artefact

- Ship one artefact in the target pillar: a talk, a tutorial, an SDK sample, or a community program slice, paired with an existing team member.
- At least one of the friction-log fixes from day 30 lands, with the new hire driving it through docs/engineering.
- First attempt at the metric this role's funding driver is measured on (see [company-type-and-driver-lookup.md](./company-type-and-driver-lookup.md)) - even a rough baseline number counts.

## Day 61-90: self-directed ownership

- Own one recurring program slice without a pairing partner (a content series, a community ritual, an integration line).
- Deliver a written plan for the funding-driver metric: what "good" looks like in two quarters and how it will be tracked.
- Manager and new hire jointly decide, in writing, whether the 90-day evidence supports continuing at the current scope, adjusting it, or escalating a concern.

## Early-warning check

A hire who has not shipped the day-30 friction log, the day-60 artefact, and a first metric attempt by day 90 needs an explicit conversation, not an extended grace period assumed silently. Treat the three milestones as a decision trigger, the same way sales-hiring treats a missed 90-day quota-ramp milestone.
