# Templates

Fill every bracket with the user's facts. Never invent a feature, number or guest.

**Season announcement** (post on every channel, two weeks before episode 1)

```
[Show name] is back: [N] live sessions, [weekday] at [time + time zone], on [home platform].
Each week we [format, e.g. pair-program with someone building on (product)].
Lineup: [date] [guest] - [what they will build]. [date] ...
Send the question you want answered live: [link].
```

**LinkedIn event description**

```
Live: [guest] and [host] [verb] [problem] with [technology].
You'll leave knowing [one concrete outcome].
Ask questions in the comments during the stream; we answer them on air.
[Host], [role] at [company]. [Guest], [role] at [their company].
```

**Pinned chat rules**

```
Welcome. Ask anything about [topic]; mods relay questions to [host].
Be kind; our code of conduct: [link].
Only mods post links. Found a security issue? Don't post it here: [disclosure channel].
```

**Moderator brief**

```
Show: [name], [date/time], home chat: [platform]; you own: [chat].
Presets on before start: [list]. Raid preset: [command or toggle].
Relay questions in this format: "@[host] Q from [user]: [question]".
Escalate to [backup] on [channel]. Security reports: delete, DM the reporter [disclosure link].
Note timestamps of good answers in [doc] for clips.
```

**Guest invitation**

```
Hi [name], I saw [specific thing they built or streamed]. Would you pair with [host] live on [date] for [length]
to build [concrete thing] with [product/technology]? We handle setup and a demo account; you keep the code.
We'll promote your episode and raid your channel afterwards if you stream.
```

**End-of-stream raid message**

```
That's it for today. We're raiding [channel], who's [what they're doing] - say hi from [show name].
```

**Disclosure lines**

```
Staff on a personal channel (title + on screen + aloud, plus the branded-content tick): "I work at [company]; this is our product."
Paid guest or streamer: tick the platform's branded content / paid promotion box, and say "[company] is paying for this stream."
```

**Recap post** (within 48 hours)

```
[Show name] #[n]: [what we built].
Questions from chat we answered: [Q1 -> chapter link], [Q2 -> docs page we fixed].
Full replay: [link]. Next: [date] with [guest].
```
