# DevRel source list

Each entry carries the date its liveness was last confirmed, so staleness is visible at a glance.

Statuses:

- **active**: dated item ≤ ~3 months old when confirmed.
- **stale**: reachable, newest dated item > ~6 months.
- **unverified**: the fetch failed, or the page renders no dates (reason recorded, never assumed dead).
- **dead**: parked, resold, or non-resolving on every surface it has.

"not stated" means the source publishes no audience figure - do not invent one. "What they're selling" discloses the incentive: almost nothing in this field is conflict-free, so the flag exists for disclosure, not disqualification.

Pillar column maps to the four DevRel pillars: advocacy, marketing, enablement (docs/DX), community. Re-verify anything here before recommending it (see SKILL.md, Freshness and ownership check).

## Video

Video platforms answer an automated fetcher with a consent wall (302 to a consent domain), so subscriber counts and upload dates are not observable that way. Do not list a channel on memory alone. DevRelCon talks are also published on developerrelations.com, which is fetchable; prefer that surface and label any channel entry "corroborated via a companion surface; channel itself unobserved".
