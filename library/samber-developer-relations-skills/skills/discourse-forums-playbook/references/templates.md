# Discourse forum templates

Every template below uses a fictional product, Tidepool, a hosted queue service. Replace the bracketed parts and the product facts with the user's own. Staff post them under their own names; no template is ever posted from an invented account.

## Contents

- Welcome or banner topic
- Category About posts
- Founding-member invite
- Seed-from-ticket consent request
- First-post welcome reply
- Solution nudge
- Duplicate and move notes
- Weekly ritual topic
- Announcement topic

## Welcome or banner topic

```
// ✓ Good - says what the place is, where things go, and how fast staff answer
Welcome to the Tidepool forum

This is where Tidepool users help each other run queues in production.
The Tidepool team reads every new topic on weekdays and answers within one working day.

- Stuck or seeing an error? Post in Support, one question per topic, with your client version and the full error.
- Built something with Tidepool? Show it in Show and tell.
- Want something changed? Feedback. We reply to every request with a decision, even when it is "not now".
- Billing or account access? Email support@[domain]; never post keys or invoices here.

Please read the guidelines before your first post.

// ✗ Bad - a mission statement with no instruction
Welcome to our vibrant community! We are so excited to have you here.
Feel free to explore, share, and connect with fellow innovators!
```

## Category About posts

```
Support - Questions about using Tidepool. One problem per topic. Include client version, language and the full error.
Mark the reply that solved it, so the next person finds the answer.

Show and tell - Projects, plugins and write-ups built on Tidepool. Self-promotion is welcome here and only here:
one topic per project, post updates as replies.

Feedback - Feature requests and product criticism. Search first and like an existing topic instead of opening a duplicate.
```

## Founding-member invite

```
Subject: Help us start the Tidepool forum?

Hi [name],

You answered three other users' questions in our GitHub issues last quarter, including the
retry-backoff one we still link to. We're opening a forum on [date] so those answers stop
getting buried in closed issues.

Would you join the first group, two weeks before it opens publicly? The ask: answer
questions in your area when you see them, for the first three months. In return you get early
access, a Founding member badge and a direct line to the queue team.
Everything posted before the opening becomes public on [date].

No is a fine answer.
[your name], [role] at Tidepool
```

## Seed-from-ticket consent request

```
Hi [name],

Your question last month about dead-letter queues filling up after a deploy is one we get often.
Could we post it on the new public forum with the answer, so others find it?

Two options:
1. You post it yourself (we'll reply with the fix and mark it solved), or
2. We post a rewritten version under my name, with no company names or logs from your account.

If you'd rather we didn't, nothing changes.
```

## First-post welcome reply

```
Welcome, [name]. [One sentence that answers or acknowledges their actual post.]
[If a question:] When a reply fixes it, click "Solution" under that reply so it shows as solved.
```

## Solution nudge

```
Did [username]'s reply fix it? If so, please mark it as the solution.
If not, post what you see now and we'll keep going.
```

## Duplicate and move notes

```
Duplicate: Closing this as a duplicate of [link], which has a solved answer.
If that fix doesn't match your case, open a new Support topic with your version and error, and link this one.

Move: Moved to Support from Feedback, since this is a how-do-I question. Nothing else changed.
```

## Weekly ritual topic

```
Title: What are you building this week? ([week of date])

Reply with one thing you're working on with Tidepool, and one thing that's in your way.
Team members answer the blockers in this thread or open a Support topic for them.
```

## Announcement topic

```
Title: Tidepool 4.2: per-queue rate limits

What changed, in two sentences.
Who needs to act, and by when.
Link to the changelog and the migration guide.

Questions about this release: reply here. Problems with your setup: open a Support topic.
```
