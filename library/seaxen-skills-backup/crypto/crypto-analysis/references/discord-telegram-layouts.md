# Discord / Telegram Layout Guide

Use these rules when rendering crypto-analysis results in chat:

## Shared rules
- Put the bias/verdict on the first line or second line.
- Keep the report compact: price, TA, S/R, verdict, trade plan, then optional extras.
- Prefer plain bullets over tables.
- Omit unavailable optional sources instead of printing missing-key warnings.

## Discord layout
- Title line should be bold.
- Use compact bullets with short labels.
- Keep links on one final line if possible.

Example:
**Bittensor (TAO)**
• Bias: SHORT | 15m short | 4h short | 1d long
• Price: $287.36 | 24h: -6.57% | Vol: $208.3M
• Verdict: SHORT
• Trade: entry $300.89 | stop $307.47 | target $295.57 | RR 0.81
• Links: TV <url> | CG <url>

## Telegram layout
- Title line should be plain text.
- Keep bullets simple and readable on mobile.
- Avoid nested lists and decorative symbols.

Example:
Bittensor (TAO)
• Bias: SHORT | 15m short | 4h short | 1d long
• Price: $287.36 | 24h: -6.57% | Vol: $208.3M
• Verdict: SHORT
• Trade: entry $300.89 | stop $307.47 | target $295.57 | RR 0.81
• Links: TV <url> | CG <url>

## Compact terminal layout
- Use the same information, but it can be slightly denser.
- This is the fallback when no platform-specific layout is requested.
