# Adding Crypto MCP Servers with Bitwarden-Injected API Keys

Pattern used in this session to add **Coinglass** and **CoinMarketCap** MCPs using Bitwarden-injected keys.

## Bitwarden Env Var → MCP Config Mapping

| Bitwarden Injected | Wrapper Script Exports | MCP Server Expects |
|---|---|---|
| `COINGLASS_KEY` | `COINGLASS_API_KEY` | `CG-API-KEY` header |
| `COINMARKETCAP_KEY` | `COINMARKETCAP_API_KEY` | `X-CMC_PRO_API_KEY` header |

The wrapper script is the translation layer:
```bash
#!/usr/bin/env bash
export COINGLASS_API_KEY="${COINGLASS_KEY}"
exec node /path/to/built/dist/index.js
```

## Hermes config entry (auto-generated by `hermes mcp add`)

```yaml
mcp_servers:
  coinglass:
    command: /mnt/tb/hermes/scripts/mcp-servers/coinglass-mcp/run.sh
    enabled: true
    env:
      COINGLASS_KEY: ${COINGLASS_KEY}
  coinmarketcap:
    command: /mnt/tb/hermes/scripts/mcp-servers/coinmarketcap-mcp/run.sh
    enabled: true
    env:
      COINMARKETCAP_KEY: ${COINMARKETCAP_KEY}
```

The `${VAR}` syntax means "read from process env at startup" — Bitwarden injects these before Hermes starts.

## Two Install Paths

### 1. npm package not published (Coinglass) → local build + wrapper

```bash
cd /mnt/tb/hermes/scripts/mcp-servers
git clone https://github.com/GPSxtreme/mcp-coinglass.git coinglass-src
cd coinglass-src
pnpm install
pnpm run build
```

Wrapper (`coinglass-mcp/run.sh`):
```bash
#!/usr/bin/env bash
export COINGLASS_API_KEY="${COINGLASS_KEY}"
exec node /mnt/tb/hermes/scripts/mcp-servers/coinglass-src/dist/index.js
```

### 2. Python package on PyPI/GitHub (CoinMarketCap) → uvx from git

Wrapper (`coinmarketcap-mcp/run.sh`):
```bash
#!/usr/bin/env bash
export COINMARKETCAP_API_KEY="${COINMARKETCAP_KEY}"
exec uvx --from git+https://github.com/longmans/coin_api_mcp coin-api
```

Note: executable name was `coin-api`, not `coinmarketcap-mcp` — check `pyproject.toml` `[project.scripts]`.

## Verification

```bash
# Manual run - should print tool list and wait on stdio
/mnt/tb/hermes/scripts/mcp-servers/coinglass-mcp/run.sh
/mnt/tb/hermes/scripts/mcp-servers/coinmarketcap-mcp/run.sh

# Hermes test - full handshake including tools/list
hermes mcp test coinglass
hermes mcp test coinmarketcap
```

## Pitfalls

- **Coinglass requires upgraded API plan** — all tools return success but empty/error data on free tier
- **`mcp test` timeout** for stdio servers is ~10s, local build starts fast enough
- **Bitwarden env vars only available inside Hermes process** — test with `COINGLASS_KEY=xxx /path/to/wrapper.sh` outside Hermes
- **Python MCP server errors on direct run** — "I/O operation on closed file" is expected (waits for JSON-RPC on stdin), ignore and test via Hermes
