## Stream Timeout Prevention (Hematology-Specific)

**Problem**: Large Hematology notes (150-200+ lines with tables, mermaid diagrams) caused stream timeouts

**Solution**:
- Individual `write_file` calls per note (never batch in `execute_code`)
- Large notes (>180 lines) split into 2-3 chunks:
  - **Chunk 1**: Frontmatter + Learning Objectives + Definition/Epidemiology + Pathophysiology + Clinical Features
  - **Chunk 2**: Diagnosis/Workup + Differential Diagnosis + Investigations
  - **Chunk 3**: Management + FCPS/MRCP High-Yield + Viva Questions + Confusions/Mnemonics + Mind Map + Revision Card + Trackers + Scorecard + Navigation
- **Batch size**: 5-10 notes per session
- **Practical limit**: 5-10 notes per session using individual `write_file` calls
