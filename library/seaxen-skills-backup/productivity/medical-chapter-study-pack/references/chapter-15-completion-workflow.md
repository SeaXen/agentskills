## Key Lessons Learned

### Workflow Optimizations
1. **Create hierarchy/MOC first** → Provides clear roadmap for topic creation
2. **Create template first** → Ensures consistency across all topics
3. **Web search validation at each section** → Catches gaps early
4. **Update MOC/Hierarchy after each batch** → Maintains accurate progress tracking
5. **File count verification** → Quick sanity check (22 topics + 2 supporting + 1 template = 24 files)

### File Size Guidelines
- Core topics: 15-25 KB (full FCPS/MRCP content)
- Overview/assessment topics: 5-7 KB (scaffold/complete)
- Complex topics (malignancies, AKI): 15-25 KB
- Overview/complex (Malignancies, Glomerular): 18-22 KB

### Content Structure Standards
Each topic file includes:
1. Frontmatter with tags, davidson_chapter, topic_category, status
2. Learning Objectives
3. Key Concepts tables
3. Mind Maps (Mermaid)
