## File Naming Convention Used

- Descriptive, readable filenames with spaces (not underscores)
- Parentheses for disambiguation when needed
- Consistent extension: `.md`
- Topic Category in frontmatter matches section theme

## Status Progression

```
scaffold → full-fcps-mrcp-topic-note
```

Each topic starts as `status: scaffold` and is upgraded to `status: full-fcps-mrcp-topic-note` upon completion.
