# Examples

## Single PDF
```bash
/mnt/tb/hermes/scripts/obsidian-ingest.sh /path/to/paper.pdf
```

## DOCX with tag
```bash
/mnt/tb/hermes/scripts/obsidian-ingest.sh --tag lecture-notes /path/to/lecture.docx
```

## Whole folder
```bash
/mnt/tb/hermes/scripts/obsidian-ingest.sh --recursive /path/to/folder
```

## Custom destination
```bash
/mnt/tb/hermes/scripts/obsidian-ingest.sh --folder Knowledge/Imported /path/to/file.pptx
```

## Quick verify
```bash
/mnt/tb/hermes/scripts/obsidian-ingest.sh --help
/mnt/tb/hermes/venvs/markitdown/bin/markitdown --version
```
