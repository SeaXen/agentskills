## Proven Workflow (This Session)

### Phase 1: Scaffold (One-time)
1. Create hierarchy file with all domains and topic wikilinks
2. Update MOC with hierarchy link and starter queue
3. Verify hierarchy matches Davidson chapter boundaries

### Phase 2: Batch Production (Iterative)
1. **Read hierarchy** → select next N uncompleted topics
2. **Write full notes** with complete template (use `template-completeness-checklist.md`)
3. **Update MOC** → add ✅ markers, increment progress count
4. **Update hierarchy** → confirm topic link matches filename exactly
5. **Repeat** until 25/25 complete

### Phase 3: Verification (Critical)
- File count = hierarchy count = MOC progress count
- All wikilinks resolve (exact filename match)
- All notes pass template completeness checklist
- No placeholder text in MCQs/SBAs/Flashcards

## Key Patterns Established

### Naming Conventions
- **No slashes in filenames** → use `Malignant Hyperthermia Neuroleptic Malignant Syndrome.md` not `Malignant Hyperthermia / NMS.md`
- **Wikilinks match filenames exactly** → `[[Malignant Hyperthermia Neuroleptic Malignant Syndrome]]`
- **Septic Shock separate from Sepsis and Septic Shock** → both exist as distinct high-yield topics

### Template Compliance
- First 6 notes: full template ✅
- Next 10 notes: missing ~50% sections (fixed in remediation pass)
- Remediation: patched all 10 with full Must Know/Should Know, MCQs, SBAs, Flashcards, Answer Keys, Common Confusions, Mnemonics, Mind Maps, Flowcharts, Trackers, Exam Modes

- **Anatomy**: Gray's + Davidson
- **Physiology**: Guyton & Hall + Ganong + Davidson
- **Clinical**: Davidson + PasTest + personal notes + guidelines (SSC, NICE, RCP, AAGBI, RCOG, BGS)
