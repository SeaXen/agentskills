# Channel Workflow and System Rules

Use this reference when the user is running the medicine study system across Discord channels as well as an Obsidian vault.

## Proven channel split

### Index/system channel
Use a dedicated channel (for this user, `#index`) for:
- skill editing
- system-rule updates
- exporting skill/reference files into the repo
- vault structure maintenance
- master planning

### Chapter channels
Use separate chapter channels for:
- topic-specific study
- chapter-specific source hierarchy
- note development and revisions
- MCQ/SBA expansion
- flashcards and recall prompts
- chapter-specific exam traps and clarifications

## Final governance notes worth exporting

For a mature study vault, export these user-facing notes into `00_Index/`:
- `All System Rules.md`
- `Medicine Chapter Channel Plan.md`

These complement the existing roadmap/tracker/dashboard/how-to guides and make the system easier to maintain across sessions.

## Channel naming pattern

Prefer:
- lowercase names
- hyphen-separated names
- one channel per major Davidson chapter

Allow optional subchannels later for broad chapters such as nephrology, cardiology, or respiratory medicine.

## Operational rule

Keep system changes in the index channel. Keep chapter-content work in the relevant chapter channel. When chapter rules become stable, fold them back into chapter-specific override rules or memory so future sessions start with the right context.
