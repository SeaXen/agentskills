# Chapter Channel Rule Packs

Use this reference when the user is expanding the medicine Discord/vault workflow from a generic system into per-chapter working channels.

## Proven system split
- `#index` is the system/index channel for skill edits, rule updates, exports, and vault maintenance.
- Chapter channels are for topic-specific study, source preferences, MCQ/SBA work, flashcards, and chapter note development.

## Governance notes to maintain in the vault
- `00_Index/All System Rules.md`
- `00_Index/Medicine Chapter Channel Plan.md`
- `00_Index/Chapter Rules Index.md`
- `00_Index/Chapter-Specific Rule Template.md`

## Proven chapter-rule folder layout
```text
00_Index/
├── Chapter Rules Index.md
├── Chapter-Specific Rule Template.md
└── Chapter Rules/
    ├── Cardiology Channel Rules.md
    ├── Respiratory Channel Rules.md
    ├── Neurology Channel Rules.md
    ├── Nephrology Channel Rules.md
    ├── Gastroenterology Channel Rules.md
    ├── Endocrinology Channel Rules.md
    ├── Hematology Channel Rules.md
    ├── Rheumatology Channel Rules.md
    └── Infectious Disease Channel Rules.md
```

## High-value content inside each chapter rule note
- chapter identity and channel purpose
- reference priority by anatomy / physiology / pathology / interpretation / management
- output-style rules (Markdown, wikilinks, callouts, Mermaid)
- chapter-specific interpretation priorities
- procedure mini-sections to include routinely
- exam emphasis: long answers, short notes, viva traps, MCQ traps, SBA scenarios
- special-situation cautions
- must-know / should-know / nice-to-know topic priorities
- a short channel-memory summary suitable for durable memory
