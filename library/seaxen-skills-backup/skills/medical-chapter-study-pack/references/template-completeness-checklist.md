# FCPS/MRCP Note Template — Completeness Checklist

Use this checklist after writing ANY topic note. Do not mark `status: full-fcps-mrcp-topic-note` until ALL items are verified.

- [ ] Frontmatter with all fields (tags, chapter, davidson_part, davidson_chapter, topic, exam, references, related, status)
- [ ] Title + Related wikilinks
- [ ] Important callout box
- [ ] Learning Objectives (3-5 bullets)
- [ ] Definition
- [ ] Core Anatomy (if applicable)
- [ ] Core Physiology (if applicable)
- [ ] Normal Values / Important Cut-offs (table)
- [ ] Classification (table)
- [ ] Etiology / Causes
- [ ] Risk Factors
- [ ] Pathophysiology
- [ ] Clinical Features (early vs late / compensated vs decompensated)
- [ ] Approach / Algorithm (stepwise)
- [ ] Investigations
- [ ] Interpretation Frameworks
- [ ] Diagnosis
- [ ] Differential Diagnosis
- [ ] Tables / Comparison Charts
- [ ] Management
- [ ] Drug Interactions / Contraindications / Comorbidity Cautions
- [ ] Procedures / Indications / Contraindications
- [ ] Procedure Mini-Sections
- [ ] Complications
- [ ] Red Flags / Emergencies
- [ ] Prognosis
- [ ] Topic Correlation
- [ ] Special Situations (pregnancy, elderly, organ dysfunction, immunocompromised)
- [ ] FCPS/MRCP High-Yield Points (5-10 bullets)
- [ ] Common Viva Questions (5+)
- [ ] Common Confusions / Exam Traps
- [ ] Mnemonics
- [ ] Mind Map (mermaid)
- [ ] Flowchart (mermaid)
- [ ] Suggested Visuals / Image Notes
- [ ] Suggested Video References
- [ ] One-Page Revision Summary
- [ ] 24-Hour Recall Prompts (4 bullets)
- [ ] 7-Day / 15-Day / 30-Day Revision Tracker (checkboxes)
- [ ] Must Know / Should Know / Nice to Know (3 sections with bullets)
- [ ] My Weak Points (3 bullets)
- [ ] Self-Test Scorecard (5 categories, /10 each, total /50)
- [ ] Exam Answer Modes (Long Answer, Short Note, Viva, Ward Case, Last-Night Sheet)
- [ ] Summary
- [ ] **MCQs (10) — complete with A-D options**
- [ ] **SBA Questions (10) — clinical stems with A-D options**
- [ ] **Flashcards (5-10) — Q/A format**
- [ ] **Answer Key with Explanations — MCQs + SBAs with brief rationale**
- [ ] Status line at end: `**Status**: Full FCPS/MRCP topic note completed — YYYY-MM-DD`

## Quality Gates

- [ ] All tables render correctly in markdown
- [ ] All mermaid diagrams use valid syntax
- [ ] All wikilinks use exact filename (no slashes, no special chars)
- [ ] No placeholder text like "(Questions and answers follow...)" — actual content present
- [ ] Cross-references to related topics use `[[wikilink]]` format
- [ ] Source references in frontmatter match content sources

## Batch Verification (When Creating Multiple Notes)

- [ ] Read hierarchy file first — confirm topic list
- [ ] Create/update each note with full checklist above
- [ ] Update MOC: add ✅ markers, update progress count
- [ ] Update hierarchy: confirm all topics present, links match filenames
- [ ] Verify no missing topics from hierarchy
- [ ] Verify no duplicate topics
