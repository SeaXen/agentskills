# Medical Mnemonics Bank

## Hepatology

### CHILD-PUGH
- **C**hild-Pugh: **Bilirubin, Albumin, INR, Ascites, HE**
- **I**NR / **R**enal = MELD
- **R**efractory Ascites: **LVP + Albumin 8g/L → TIPS**
- **R**efractory Varices: **Early TIPS (Child B/C, HVPG >20)**
- **H**epatic Encephalopathy: **West Haven I-IV, Lactulose, Rifaximin**
- **H**RS-AKI: **Terlipressin + Albumin → TIPS → Transplant**
- **H**PS: **Delayed bubbles + PaO₂<80 = Transplant**
- **O**rthotopic Transplant: **Indications: MELD≥15, ALF, HCC Milan, Metabolic**
- **S**coring Systems: **Child A/B/C (5-6/7-9/10-15); MELD (<10 Low, 10-19 Mod, 20-29 High, ≥40 Urgent)**
- **M**ajor Scores: **Child A/B/C (5-6/7-9/10-15); MELD (<10 Low, 10-19 Mod, 20-29 High, ≥40 Urgent)**
- **A**scites/Portal HTN: **SAAG ≥11 = Portal HTN; SBP PMNs≥250 → Ceftriaxone+Albumin**
- **S**ob/Dyspnoea: **HPS = Delayed bubbles, PaO₂<80; PoPH = mPAP>25, PVR>240**
- **T**reatment Underlying: **Treat Cancer = Best for Paraneoplastic**
- **E**mergency: **ALF = King's College; ACLF = CLIF-C ACLF**
- **M**alignant: **HCC Milan (Single≤5cm or ≤3cm×3), BCLC 0/A/B/C/D**
- **A**nchoring: **Remember: Compensated vs Decompensated = Ascites/Varices/HE/Jaundice**

### MELD
- **M**ELD = **3.78×ln(bili) + 11.2×ln(INR) + 9.57×ln(Cr) + 6.43**
- **E**xcpt: **Creatinine capped at 4.0** (dialysis = 4.0)
- **L**iver Allocation: **MELD-Na = MELD + Na adjustment**; Na capped 125-137
- **D**ialysis = Cr 4.0

### MADDREY
- **M**addrey DF: **4.6×(PT-ctrl) + Bil mg/dL ≥32 = Steroids**
- **A**DD **GAHS ≥9** supports, **ABIC ≥6.71** supports
- **D**D **Lille Day 7**: **<0.45 Continue, >0.56 Stop**
- **R**esponse: **Cr ↓≥25% by Day 3** = Continue terlipressin
- **E**xclusion: **Infection, Bleed, Renal, Pancreatitis, DM**
- **Y**oung/Old: **Hepatic 5-35, Neuro 15-45, ALF <18**

### CHILD-PUGH
- **C**hild-Pugh: **Bilirubin, Albumin, INR, Ascites, HE**
- **H**ow to Score: **1/2/3 points each → A(5-6), B(7-9), C(10-15)**
- **I**NR / **L**ow Albumin / **D**ysfunctional Coagulation
- **P**rolonged PT / **U**ncontrolled Ascites / **G**rade HE
- **H**epatic **E**ncephalopathy

### MELD
- **M**ELD = **3.78×ln(bili) + 11.2×ln(INR) + 9.57×ln(Cr) + 6.43**
- **E**xception Points: **HCC Milan=22, HPS=22, PoPH=22**
- **L**iver Allocation: **MELD-Na = MELD + Na adj**; Na capped 125-137
- **D**ialysis = Cr 4.0

### ALD
- **A**ST:ALT **>2:1** = ALD
- **L**ille Day 7: **<0.45 Continue, >0.56 Stop**
- **D**F Maddrey: **≥32 = Steroids**
- **S**teroid: **Pred 40mg ×28d** if DF≥32; **Ciprofloxacin 500mg** prophylaxis
- **C**orticosteroid Contraindications: **Infection, Bleed, Renal, Pancreatitis, DM**
- **O**rgan Failure: **Lille >0.56 = Stop Steroids**
- **R**elapse Prevention: **Acamprosate (renal), Naltrexone (avoid decomp), Baclofen (safe cirrhosis)**
- **E**nable Thiamine: **100mg IV TDS before glucose**
- **M**addrey DF: **4.6×(PT-ctrl) + Bil mg/dL ≥32 = Steroids**
- **G**AHS ≥9: Supports steroids
- **A**BIC ≥6.71: Supports steroids
- **M**aintenance: **Zinc 50mg TDS** (Maintenance, Lifelong)
- **P**regnancy: **Continue Zinc, Reduce Chelator Dose**

### CHILD-PUGH vs MELD
- **C**hild-Pugh: **Clinical + Lab** (subjective ascites/HE); **MELD**: **Objective lab-based, transplant allocation**

### FIB-4 vs NFS
- **F**IB-4: **1st-line**, age+AST+ALT+platelets; **N**FS: **Adds BMI, IFG, albumin**; use both for NAFLD
- **F**IB-4: **Age×AST/(Plt×√ALT)**; **<1.3 low, >2.67 high** risk F3-F4
- **N**FS: **Age, BMI, IFG, AST/ALT, Plt, Alb**; **<-1.455 low, >0.676 high** risk
- **F**ibroScan: **Gold standard non-invasive**; **<8, 8-9, 9-12, >12 kPa = F0-F1, F2, F3, F4**
- **A**PRI: **AST/ULN/Plt×100**; **<0.5 no fibrosis, >1.5 cirrhosis**

### HCC
- **H**CC Surveillance: **Cirrhosis q6mo US±AFP**
- **C**CR: **Ablation/Resection/Transplant**
- **L**I-RADS: **LR-5 Definite HCC, LR-4 Probable, LR-3 Follow-up, LR-M Non-HCC Malignant**
- **I**maging: **APHE + Washout + Capsule = LR-5**
- **B**CLC: **0/A Curative, B TACE, C Systemic (Atezo/Bev), D BSC**
- **C**urative: **Ablation <3cm, Resection Child A, Transplant Milan**
- **L**imb Salvage: **Endoprosthesis >90%, Rotationplasty (Young, Distal Femur/Tibia)**
- **C**RC: **CRC Surveillance: q6mo US±AFP**
- **M**etastases: **Lung (All), Skip (Osteo), Bone Marrow (Ewing)**
- **C**chondro Grades: **Gr1: Marginal; Gr2-3: Wide; Dediff: Surgery + Doxo**

### MAP
- **M**AP Protocol: **Neoadj MTX 12g + Doxo 37.5 + Cis 120 q3w ×2-3** → Surgery → **Adj MAP ×4-6**

### VAC/IE
- **V**AC/IE: **Alternating q3w: VAC (Vinca/Act-D/Cyclo) ↔ IE (Ifos/Etopo) ×14-17**

### LIMB Salvage
- **L**imb Salvage: **Endoprosthesis >90%, Rotationplasty (Young, Distal Femur/Tibia)**
- **A**rthroplasty: **Endoprosthesis (>90%), Rotationplasty (Young, Distal Femur/Tibia)**
- **R**otationplasty: **Preserves Nerve, Ankle=Knee, Functional Superior**
- **A**mputation: **Neurovascular Involvement, Infection, Failed Salvage**

### METASTASES
- **M**etastases: **Lung (All), Skip (Osteo), Bone Marrow (Ewing)**

### CHONDRO
- **C**chondrosarcoma: **IDH1/2 Mut (50-70%)**, **Adults >40**, **Surgery Only** (Gr1 Marginal, Gr2-3 Wide)
- **D**ediff: **Surgery + Doxo**

### POLYCYSTIC KIDNEY
- **P**olycystic Kidney: **ADPKD (PKD1/PKD2), ARPKD (PKHD1)**
- **O**rganomegaly: **Kidney, Liver, Pancreas, Spleen**
- **L**iver Cysts: **Common in ADPKD, usually asymptomatic**
- **Y**oung Onset: **ADPKD adults, ARPKD infants/children**
- **C**KD Progression: **HTN, Proteinuria, Hematuria, UTIs, Stones**
- **S**creening: **Family Members (US, Genetic Testing)**
- **S**ymptoms: **Flank Pain, Hematuria, HTN, UTIs**
- **S**urveillance: **Annual US, BP, Renal Function**
- **C**yst Infection: **Fever, Flank Pain, Leukocytosis → Antibiotics (cipro/TMP-SMX)**
- **S**econdary Hypertension: **Common, Early, Aggressive Control (ACEi/ARB)**
- **E**SRD: **Dialysis/Transplant** (ADPKD ~10% reach ESRD by 60)
- **T**ransplant: **Preferred RRT**, pre-emptive if possible
- **I**nfants: **ARPKD → Neonatal respiratory distress, hepatic fibrosis**
- **S**ystemic: **Intracranial Aneurysms (ADPKD), Mitral Valve Prolapse, Diverticulosis**

## Endocrinology

### HYPERTHYROIDISM
- **G**raves: Diffuse goitre, ophthalmopathy, pretibial myxoedema, TRAb+
- **T**oxic Nodule: Solitary/multinodular, suppressed TSH, normal TRAb
- **T**hyroiditis: Painless/Subacute/Postpartum, transient thyrotoxicosis → hypothyroidism

### HYPOTHYROIDISM
- **P**rimary: TSH↑, T4↓; **S**econdary: TSH↓/normal, T4↓
- **M**yxedema: Non-pitting oedema, hypothermia, bradycardia, coma

### DIABETES
- **D**iagnosis: HbA1c≥48, FPG≥7, 2hPG≥11.1, Random≥11.1 + symptoms
- **C**omplications: Micro (retino, nephro, neuro), Macro (CVD, PVD, cerebrovascular)
