## Key High-Yield FCPS/MRCP Topics per Section

### Sodium & Water (5)
- Hyponatraemia: Schwartz-Bartter, SIADH vs CSW, correction limits, 3% saline dosing
- Hypernatraemia: Free water deficit formula, DI workup (water deprivation test), central vs nephrogenic
- SIADH: All 6 criteria, treatment ladder (fluid restrict → demeclocycline → tolvaptan)
- Diabetes Insipidus: Central vs nephrogenic, water deprivation test, desmopressin
- Cerebral Salt Wasting: Volume status key (hypovolaemic), saline + fludrocortisone

### Potassium (2)
- Hypokalaemia: U waves, ST depression, urine K+ cutoff (>20 = renal), Mg first, IV KCl rates
- Hyperkalaemia: ECG progression (peaked T → sine wave), 4-step Rx (Ca gluconate → insulin/dextrose → salbutamol → dialysis)

### Calcium/Magnesium/Phosphate (6)
- Hypocalcaemia: Tetany signs, IV Ca gluconate 10-20mL 10%, chronic: Ca + alfacalcidol
- Hypercalcaemia: PTH-based differentiation (malignancy vs primary HPT), hydration → zoledronic/denosumab
- Hypomagnesaemia: Refractory hypokalaemia/hypocalcaemia, QT prolongation, IV MgSO4 2-4g
- Hypermagnesaemia: Renal failure most common, Ca gluconate antagonist, dialysis if severe
- Hypophosphataemia: Refeeding syndrome, DKA, respiratory alkalosis, IV PO4 15-30mmol/6-12h
- Hyperphosphataemia: CKD-MBD, binder selection (Ca vs non-Ca), Ca×P <4.5, calciphylaxis

### Acid-Base (5)
- Metabolic Acidosis: MUDPILES, delta ratio, Winter's formula, bicarb indications (pH<7.1)
- Metabolic Alkalosis: Urine Cl- <20 (responsive) vs >20 (resistant), saline vs acetazolamide
- Respiratory Acidosis: Acute HCO3↑1/10 vs chronic HCO3↑4/10 per 10mmHg pCO2; NIV 1st line COPD
- Respiratory Alkalosis: HCO3↓2 (acute) vs ↓5 (chronic) per 10mmHg; salicylate = mixed resp alk + met acidosis
- Mixed Disorders: Delta ratio (1-2 pure AGMA, <0.4 AGMA+NAGMA, >2 AGMA+Met Alk), delta-delta

### Metabolic Bone (4)
- Osteoporosis: DEXA T-score ≤-2.5, FRAX, bisphosphonate 1st line, drug holidays (3-5yr oral, 3yr IV), denosumab no holiday
- Osteomalacia: Low PO4, high ALP, high PTH, low Vit D; loading 50k IU/wk ×6-8wk
- Paget: Lytic→Mixed→Sclerotic; ALP disproportionately high; zoledronic 5mg IV single dose
- Renal osteodystrophy: FGF23→↓1,25(OH)2D→hypoCa→↑PTH; KDIGO PTH 2-9x ULN; binder sequencing

### Metabolic Medicine (5)
- Obesity/MetSyn: BMI≥30, IDF criteria (central obesity + ≥2), GLP-1 RA 1st line (semaglutide 2.4mg), tirzepatide >20%
- Lipid disorders: ESC LDL targets by risk, statin intensity, ezetimibe→PCSK9i→bempedoic acid
- Porphyria: AIP/VP/HCP acute; urine PBG↑↑↑ gold standard; haemarginate 3-4mg/kg IV×4d + glucose
- Wilson: ATP7B, KF rings pathognomonic, ceruloplasmin<0.2, Leipzig score≥4; penicillamine/trientine/zinc
- Haemochromatosis: HFE C282Y hom 90%; TSAT>45%, ferritin>300/200; venesection 400-500mL weekly→maintenance

## Common Pitfalls Avoided

| Pitfall | Solution |
|---------|----------|
| Stream timeout on large writes | Individual `write_file` calls per note; large notes split into 4 chunks |
| Local Navigation header format | Must use `## Local Navigation (for Dashboard UI)` (2 hashes + exact text) |
| Missing 14th section | Verify all 14 sections present before declaring complete |
| Missing viva questions | Minimum 8 per note, PACES/FCPS style with expected answers |
| Missing delta ratio in metabolic acidosis | Always include delta ratio table and delta-delta calculation |
| Missing Winter's formula | Must include for metabolic acidosis compensation |
| Missing urine Cl- in metabolic alkalosis | Urine Cl- <20 vs >20 differentiation is critical |
| Missing urine K+ cutoff in hypokalaemia | >20 = renal, <20 = extrarenal/shift |
| Missing Mg²⁺ first rule | Always state "Correct Mg²⁺ FIRST" for refractory hypokalaemia/hypocalcaemia |
| Missing calcium gluconate dose for tetany | IV 10% 10-20mL over 10 min with cardiac monitor |
| Missing correction rate limits | Hyponatraemia: 8-10/24h; Hypernatraemia: 10-12/24h; Hyperkalaemia target <5.5 |
| Missing dialysis indications | K⁺>6.5+ECG, refractory, AKI, tumour lysis |
