## FCPS/MRCP High-Yield Topics (Tier 1 - Must Know)
1. **Paracetamol**: Rumack-Matthew nomogram, SNAP 2-bag NAC protocol, staggered ingestion
2. **Salicylate**: Acid-base pattern (resp alkalosis + met acidosis), urine alkalinization, dialysis criteria
3. **TCA**: QRS widening → NaHCO₃, **NO phenytoin/flumazenil/Class Ia/Ic**
4. **Beta-Blocker**: Glucagon → HIET → vasopressors, **NO calcium/pacing**
5. **CCB**: CaCl₂ 1g IV central → HIET → vasopressors, **WBI for SR**, NO atropine/pacing
5. **Digoxin**: Fab 10-20 vials, **HyperK = Fab FIRST** (not Ca/insulin)
6. **Benzodiazepine**: Flumazenil CONTRAINDICATED: TCA, seizure hx, chronic use, head injury
7. **Methanol/EG**: Fomepizole 15→10mg/kg, folinic acid, dialysis criteria (visual → dialysis)
8. **CO**: 100% O₂ (half-life 30min), HBO criteria, SpO₂ falsely normal
9. **Cyanide**: Hydroxocobalamin 5g (safe in CO), **NO nitrites in fire/CO**
10. **Iron**: Elemental dose calc, 5 stages, deferoxamine 15mg/kg/hr, vin rosé urine, WBI
11. **Antidotes**: Key table with doses, contraindications, monitoring
12. **Lithium**: Acute >4 / Chronic >2.5+features dialysis, nephrogenic DI, SILENT syndrome
13. **NMS**: FEVER mnemonic, dantrolene 2.5mg/kg, bromocriptine 2.5mg, **NO dantrolene in serotonin**
14. **Serotonin**: Hunter criteria (clonus), cyproheptadine 12mg PO, **NO dantrolene**
14. **Antiarrhythmic**: Class Ia/Ic = NaHCO₃; Class III = Mg²⁺+pacing; Amiodarone = pulmonary/thyroid
15. **Antihypertensive**: Clonidine (naloxone partial), ACEi/ARB (hyperK), Diuretics (electrolytes)
16. **Corrosive**: Zargar grades, endoscopy 12-48h, **NO emesis/lavage/charcoal/neutralization**
17. **Hydrocarbon**: Aspiration = main danger, **NO emesis/lavage/charcoal**, CXR at 6h
18. **Mushroom**: Onset timing critical, Amanita = silibinin/penicillin G/NAC, Gyromitra = pyridoxine
