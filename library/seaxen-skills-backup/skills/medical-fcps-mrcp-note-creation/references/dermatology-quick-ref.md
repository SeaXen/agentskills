## Key Algorithms

### Psoriasis Management
```
Psoriasis → Severity → Mild (<10% BSA): TCS + Vit D analogue
                    → Moderate (10-20%): NB-UVB
                    → Severe (>20% or PASI>10): Systemic (MTX/Acitretin/Ciclosporin)
                                        ↓ Inadequate/Contraindicated
                                    Biologic: TNFα → IL-17 → IL-23 → JAKi
```

### Atopic Dermatitis Stepped Care
```
AD → Emollients → TCS (mild-mod face/flex, potent body) 
   → TCI (tacrolimus/pimecrolimus) face/flexures
   → NB-UVB
   → Ciclosporin (rapid) → MTX/AZA/MMF
   → Dupilumab (IL-4Rα) / JAKi (baricitinib/upadacitinib/abrocitinib)
```

### Urticaria Stepwise (EAACI/GA²LEN)
```
CSU → H1 std dose → 4x H1 → add H2/LTRA/doxepin → Omalizumab 300mg q4w → Ciclosporin
```

### SJS/TEN/DRESS/AGEP Differentiation
```
Acute severe drug reaction → Mucosal ≥2 sites? → Yes → Target lesions? → Yes → EM
                                      No → BSA detachment? → <10% SJS, 10-30% Overlap, >30% TEN
                          No/Limited → Fever + eosinophilia + organ? → Yes → DRESS
                                      No → Neutrophilic pustules? → Yes → AGEP
```

| **Acitretin** | 25-50 mg/day | LFT, Lipids; **Pregnancy X (3y washout)** |
| **Acyclovir (VZV)** | 800 mg 5x/day PO / 10-15 mg/kg q8h IV | Renal function |

| **Valacyclovir (VZV)** | 1g TDS × 7 days | Renal function |

## Key Dermoscopy Patterns

| Condition | Dermoscopy Features |
|-----------|---------------------|
| **BCC** | Arborizing (tree-like) vessels, blue-grey ovoid nests, leaf-like areas, spoke-wheel areas |
| **SCC** | Glomerular/coiled vessels, keratotic scale, white structureless areas |
| **Melanoma** | Atypical pigment network, irregular dots/globules, blue-white veil, regression structures, polymorphous vessels, peripheral streaks/pseudopods |
| **Seborrhoeic Keratosis** | Comedo-like openings, milia-like cysts, fissures, hairpin vessels |
| **Dermatofibroma** | Central white patch, peripheral pigment network |
| **Vitiligo** | Absent pigment network, perifollicular pigment retention |
| **Psoriasis** | Regular pinpoint vessels, white scales |
| **Lichen Planus** | Wickham striae (white cross-hatching) |

## FCPS/MRCP Viva High-Yield Topics

### Psoriasis
- Types, Koebner, Auspitz, nail changes, PASI, comorbidities, biologic sequencing

### Atopic Dermatitis
- Hanifin-Rajka/UK criteria, EASI/SCORAD, filaggrin, dupilumab/JAKi

### SJS/TEN
- BSA cutoffs: SJS <10%, Overlap 10-30%, TEN >30%; SCORTEN; HLA-B*58:01 (allopurinol), B*15:02 (carbamazepine)

### Bullous Pemphigoid vs Pemphigus
- BP: Tense bullae, Nikolsky-, DIF linear BMZ, salt-split roof
- Pemphigus: Flaccid bullae, Nikolsky+, DIF intercellular (fishnet), Dsg3/1

### Melanoma
- ABCDE, Breslow vs Clark, TNM 8th, SLNB indications, adjuvant anti-PD1/BRAFi+MEKi

### Urticaria
- Stepwise management (H1→4x→omalizumab→ciclosporin), UAS7, HAE (C4 low, C1-INH)

### Cutaneous Vasculitis
- Palpable purpura approach, IgA vasculitis (HSP) tetrad, ANCA patterns (c-ANCA=GPA, p-ANCA=MPA/EGPA)

### Dermatomyositis
- Heliotrope, Gottron, shawl/V-sign, mechanic's hands, **malignancy screen if >40**, anti-TIF1γ/NXP2/MDA5

### Vitiligo
- Segmental vs non-segmental, NB-UVB, JAK inhibitors (ruxolitinib), Koebner

### Alopecia Areata
- Exclamation hairs, yellow dots (trichoscopy), JAK inhibitors (baricitinib/upadacitinib/ruxolitinib)

### SLE Cutaneous
- Malar vs discoid vs SCLE, anti-Ro/SSA (SCLE), DIF lupus band test

### Skin Infections
- Impetigo vs ecthyma, cellulitis vs erysipelas vs nec fasc (LRINEC), HSV/VZV, scabies

### Genodermatoses
- Ichthyosis types (IV, X-linked, Lamellar, CIE, Epidermolytic), NF1 criteria (NIH), TSC criteria, Sturge-Weber
