# Chapter 7 Poisoning - Quick Reference for FCPS/MRCP Note Creation

## Toxidrome Quick ID (Must Know)
| Toxidrome | Key Features | Antidote |
|-----------|--------------|----------|
| **Cholinergic** | SLUDGE/DUMBELLS + fasciculations + bronchorrhea | Atropine + Pralidoxime |
| **Anticholinergic** | Hot, dry, red, blind, mad, full | Physostigmine (restricted) |
| **Sympathomimetic** | WET (diaphoresis), HTN, tachy, agitation, hyperthermia | Benzo 1st line; NO β-blockers (cocaine) |
| **Sedative-Hypnotic** | CNS depression, resp depression, hypotonia | Flumazenil (restricted: TCA, seizure hx, chronic benzo) |
| **Opioid** | Pinpoint pupils + resp depression + coma | Naloxone (titrated 0.04-0.1mg) |

## High-Yield Antidote Quick Reference

| Toxin | Antidote | Dose | Key Contraindication |
|-------|----------|------|---------------------|
| **Paracetamol** | NAC (SNAP 2-bag) | 200mg/kg/4h → 100mg/kg/16h | Anaphylactoid during Bag 1 |
| **Opioid** | Naloxone | 0.04-0.1mg IV q2-3min → RR>10 | Precipitated withdrawal (titrate) |
| **TCA** | NaHCO₃ | 1-2 mEq/kg bolus → pH 7.50-7.55, QRS<100 | **NO phenytoin/flumazenil/Class Ia/Ic** |
| **Beta-blocker** | Glucagon + HIET | Glucagon 5-10mg IV → HIET 1U/kg + D50W | NO calcium/pacing/atropine |
| **CCB** | Calcium chloride + HIET | CaCl₂ 1g IV central q10-20min | NO atropine/pacing |
| **Digoxin** | Digoxin Fab | 10-20 vials empirical OR level×wt/100 | **HyperK = Fab FIRST (not insulin/Ca)** |
| **Cyanide** | Hydroxocobalamin | 5g IV (Cyanokit) over 15min | **SAFE in CO co-exposure** |
| **CO** | 100% O₂ + HBO | NRB 15L/min; HBO if COHb>25%/LOC/cardiac/pregnancy>15% | N/A |
| **Methanol/EG** | Fomepizole | 15mg/kg load → 10mg/kg q12h (dialysis: 1mg/kg/hr) | Cost; adjust in dialysis |
| **Iron** | Deferoxamine | 15mg/kg/hr IV (max 80mg/kg/24h) | NO bolus (hypotension) |
| **Salicylate** | Alkalinization + Dialysis | Urine pH 7.5-8.0 + K⁺ replacement | Dialysis if pH<7.2, renal, CNS, level>700/400 |

## Dialysis Criteria Quick Reference (AEIOU + Specific)
| Toxin | Criteria |
|-------|----------|
| **Methanol** | pH<7.3, renal failure, **visual symptoms**, level>50mmol/L |
| **Ethylene Glycol** | pH<7.3, **renal failure**, level>50mmol/L |
| **Salicylate** | pH<7.2, renal failure, **CNS toxicity**, level>700(acute)/>400(chronic) |
| **Lithium** | **>4 acute / >2.5 chronic + neuro/renal/elderly**, renal failure |
| **Theophylline** | Seizures, arrhythmias, level>100mg/L (acute) |
| **Metformin** | pH<7.15, lactate>20, refractory shock, renal failure |
| **Valproate** | Coma, level>1300mg/L, shock (CRRT preferred) |
| **Ethanol/IPA** | Rarely (severe acidosis, renal failure, hemodynamic collapse) |

## Correction Limits (Memorize)
| Electrolyte | Chronic/Asymptomatic | Acute/Symptomatic |
|-------------|---------------------|-------------------|
| **Hyponatraemia** | ≤8 mmol/L/24h | ≤10-12 mmol/L/24h |
| **Hypernatraemia** | ≤10 mmol/L/24h | ≤12 mmol/L/24h |

## Poisoning Chapter 7 - Toxin Categories (Exam Bucket)

**Analgesics**: Paracetamol (nomogram/staggered), Salicylate (alkalization/dialysis), NSAID (supportive)
**Antidepressants**: TCA (NaHCO₃, NO phenytoin/flumazenil), SSRI/SNRI (Hunter criteria, cyproheptadine), Lithium (DI, dialysis thresholds), Antipsychotic (NMS vs serotonin)
**CV Drugs**: BB (glucagon/HIET, NO β-blockers in cocaine), CCB (CaCl₂/HIET), Digoxin (Fab, HyperK=Fab first), Antiarrhythmics (Class Ia/Ic=NaHCO₃, Class III=Mg+pacing), Antihypertensives (Clonidine=naloxone, ACEi=hyperK, Diuretics=electrolytes)
**Sedatives**: Opioid (naloxone titration), Benzo (flumazenil restricted), Barbiturate (no ceiling, MDAC/alkalinization/dialysis), Z-drugs (same as benzo), Alcohol (thiamine first)
**Toxic Alcohols**: Methanol (visual loss, fomepizole, folinate), EG (oxalate crystals, fomepizole, thiamine/pyridoxine), IPA (ketosis NO acidosis, hemorrhagic gastritis, NO fomepizole)
**Environmental**: CO (100% O₂, HBO criteria), Cyanide (hydroxocobalamin preferred, NO nitrites in fire), H₂S (olfactory fatigue, nitrite/hydroxocobalamin), Heavy metals (chelation specific)
**Specific**: Iron (deferoxamine, vin rosé urine, radiopaque pills, WBI), Cocaine/Amph (benzo 1st, NO β-blockers), Cannabis/Synthetic (synthetic=full agonist severe), Mushroom (Amanita=amatoxin, silibinin+penG+NAC), Corrosive (NO emesis/lavage/charcoal/neutralization, endoscopy 12-48h Zargar), Hydrocarbon (aspiration risk, NO decontamination, CXR at 6h)
