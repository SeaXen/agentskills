# mdsagar.com — Markdown Study Note to WordPress HTML Posting

## Session workflow (2025-05-27)

### Task
Publish a full FCPS/MRCP study note (Hodgkin Lymphoma, 1565-line markdown) to `https://mdsagar.com` as a WordPress post with tags and categories.

### What worked

1. **Auth**: WordPress Application Password auth worked with user `sagar` (administrator).
2. **Categories**: Created hierarchical categories `Medicine > Hematology > Hematologic Oncology` via `ensure_category_path`.
3. **Tags**: Created tags `hematology`, `lymphoma`, `oncology` via `POST /wp-json/wp/v2/tags`.
4. **Content conversion**: Custom Python script converted markdown to WordPress-ready HTML (see `scripts/md_to_wp_html.py`).
5. **Post creation**: `POST /wp-json/wp/v2/posts` with `status: draft` succeeded. Post ID 83 created.

### Pitfalls observed

1. **Draft posts return 404 on frontend** — Expected behavior. Drafts are only visible in WP Admin edit screen. The `?p=83` URL returns "Page Not Found" until published.
2. **REST API listing drafts returned 403** — LiteSpeed/WAF on mdsagar.com blocks `?status=draft` queries even for admin users. Workaround: use the post ID directly from the creation response.
3. **Inline User-Agent needed** — mdsagar.com's WAF blocks queries with missing or Python-default User-Agent. Always use `Mozilla/5.0` or similar browser-like UA.
4. **Long HTML content** — The 1565-line markdown produced ~81KB HTML. This posted fine in one request; no chunking needed for posts under ~100KB.
5. **HTML entities in title** — WordPress escapes `&` to `&#038;` in titles. This is normal display behavior.

### Recommended tag naming for medical posts

Use lowercase specialty tags: `hematology`, `lymphoma`, `oncology`, `nephrology`, `cardiology`, `neurology`, etc.

### Security note

If credentials were shared in chat during a session, advise the user to revoke and regenerate the Application Password. Never store passwords in scripts or memory files.
