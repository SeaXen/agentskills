# /impeccable - Frontend Design & Anti-Slop Engine

$ARGUMENTS

---

## Purpose

Activates the **Impeccable** skill (`@[skills/impeccable]`) to critique, audit, shape, polish, or typeset frontend UI and eliminate generic AI design slop.

---

## Common Subcommands

- `/impeccable init` — Initialize durable PRODUCT.md and DESIGN.md context.
- `/impeccable critique <target>` — Evaluate hierarchy, UX clarity, and contrast.
- `/impeccable audit <target>` — Run technical quality, a11y, and responsive checks.
- `/impeccable polish <target>` — Final pass on spacing, tokens, typography, and alignment.
- `/impeccable bolder` / `/impeccable quieter` — Dial design intensity up or down.

---

## Execution Instructions

When `/impeccable` is triggered:
1. Load `@[skills/impeccable]`.
2. Inspect target component/page and existing styles.
3. Apply Impeccable design principles and craft floor guidelines.
